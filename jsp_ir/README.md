# 軟體再工程
## 目標
將 JSP 轉為技術中立的中間產物文件(xxx-spec.md + xxx.html)，其中 html負責原型展示，xxx-spec.md 負責規格說明，包含業務邏輯與資料結構，主要流程等。

## 驗收標準
- [ ] 將 JSP <-> IR 互轉時，保證業務邏輯完整保留，視覺規格近乎一致
- [ ] 中間產物僅交代 JSP 具備什麼功能，而不關心具體實現細節，除非必要(如遇到外部系統依賴，API等等)
- [ ] 中間產物應該以一個JSP檔案的視角為主，不應該將多個JSP檔案的內容混合在一起，應該保持單一檔案的完整性，並透過引用或連結的方式關聯其他檔案。

## 執行方法
請先幫我從建立多輪 task，挑選 DSA30900 作為實驗對象，第一輪task沒有任何的skill，僅只用一句話說明要將JSP轉為技術中立的中間產物輸出到jsp_ir/r1 。第二輪當我開始撰寫skill，並套用skill將JSP轉為中間產物的過程自動化，必須儘可能只保留必要的轉換框架，而不是將語法細節一一列入。
