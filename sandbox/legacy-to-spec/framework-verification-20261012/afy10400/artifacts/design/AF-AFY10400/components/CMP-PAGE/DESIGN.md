# CMP-PAGE 样式規格

## Overview

適用AF-AFY10400 v2 / SCR-01；证据E-02/08/20，参见 [tracking](../../../../renovation/AF-AFY10400/tracking.md)。[CSS](../../styles/CMP-PAGE.css) 由 [prototype](../../prototypes/SCR-01.html) 实际载入。DESIGN.md alpha profile依所附skill规则，未上网核对最新规范；该选择是快照基准。省略spacing/rounded群組：没有来源尺度／圓角系统；精確padding/margin在下表保留，不自創tokens。CMP-COVER没有已知可用图像颜色，故也省略colors与typography；瀏覽器原生／继承结果按实际环境核对。

## Colors

frontmatter已列可确认值；下表gradient与边框精确值也属于契约，不扩大为系统主题。缺少图片与后载calendar CSS导致最终cascade不完整：[TODO-05](../../../../renovation/AF-AFY10400/tracking.md#todo-05), [TODO-06](../../../../renovation/AF-AFY10400/tracking.md#todo-06), [TODO-07](../../../../renovation/AF-AFY10400/tracking.md#todo-07).

## Typography

以输入、body或讯息的來源宣告／继承为準。pt不改成猜测px；font实际是否存在、native控件外观与回退须浏览器验证。

## Layout

body字型继承与EUDC @font-face源条件已知、真实字体缺失；难字不能宣稱等價。主框97%、顶栏30px、绝对0/0/z9。条件print样式作用于body所有子元素，不能只局限产品容器。邊框圖槽4×12、12×4、留白5×1及icon18×16保留空槽幾何，资源缺少仍TODO-05；沒有替代圖像。原●是根L144文字，保留20×24格、置中与HTML size=-5，字体由瀏覽器原生規則解釋；不是把缺圖換成●。

## Elevation & Depth

仅使用CSS表已列的边框、层级与shadow；review.css的dashed panel为工具，不属产品。无证据的hover/focus/disabled业务状态不添加。

## Shapes

未确认圆角或shape尺度；保留原生元素及来源边框，不建立圆角token。
