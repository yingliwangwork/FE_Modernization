# AF-AFY10400：本頁必要共用行為契約 v2

僅支撐唯一根入口。分支條件、可見反應與順序在本文件維護；來源符號及模式辨識條件留在 [tracking](../../renovation/AF-AFY10400/tracking.md#v2-source-mapping)，精確傳輸契約留在介接文件。初輪 v1 的內容及審查失敗保留為輸入快照。本契約不是全系統元件標準。

## CMP-ENTRY：入口訊息與底部交接

首次顯示時依序尋找上層左側內嵌底部、父層左側內嵌底部、上層底部、父層底部。若接收者的回復頁面旗標成立，清旗標後立即停止，連入口警示也不顯示；否則若接收者能顯示通知，僅傳第一筆訊息的代碼及描述，再逐筆組裝入口警示。描述、編號、異常的不同換行形式正規化；空值成空文字。代碼不是 0/99 且沒有異常時，組成「訊息說明:\n描述\n」，非空編號接「\n錯誤編號：\n編號」；有異常時組成「異常原因:異常\n\n程式ID:系統\n\n」。以上 \n 表示換行，不修改原文標點。外部訊息呈現能力及其必要支援均可用時交給它；否則原生警示。E-09。

全頁按鈕或送出控制的點擊，在控制本身反應後嘗試清除底部通知，包含新增、刪除、匯出；清除異常被吞下。自訂訊息的確認停止事件向上傳遞，故不清底部訊息。底部視覺與旗標來源 [TODO-01](../../renovation/AF-AFY10400/tracking.md#todo-01)；外部訊息呈現內部 [TODO-03](../../renovation/AF-AFY10400/tracking.md#todo-03)。工具注入獲明示測試豁免，不改變產品的全頁作用範圍。

## CMP-REQUEST：請求、回應與共用訊息

先區分兩個共用模式，不合併其順序。頁面採用哪個模式、所需呈現能力是否可用尚未完全確認，參見 [TODO-03](../../renovation/AF-AFY10400/tracking.md#todo-03)；來源中的模式辨識只留追蹤映射。E-11/13。

**模式 A：回填後處理完成通知。** 送出前增加活動記錄、建立或取得遮罩並顯示；本頁未設定逾時，不追加時間限制。收到傳輸成功且可解析的回應後，訊息代碼 0 執行成功反應，其餘或沒有訊息執行拒絕反應；解析內容缺省則停止本頁回應反應。回填／下載交接完成才處理完成通知；該過程例外先觸發診斷警示，完成處理仍可能繼續。傳輸失敗沒有配置本頁的拒絕回填，但完成處理仍可呈現文字內容。E-10/11。

完成時先取得訊息：若沒有解析資料而有文字，取其中已識別的頁面本文區段並將原有換行標記轉為換行；若未識別本文開始位置，使用全部文字。此為代碼 -1 的錯誤，識別形式與限制保留在追蹤。接著活動記錄減一、调整遮罩尺寸、清除本請求已存在的逾時到期；沒有訊息時，只有活動請求為 0 且没有訊息活動才隱藏。描述按字面反斜線加 n 分隔、累積、去頭尾空白；若有底部接收者則交通知。整數代碼 0 為藍色，其餘整數紅色，非整數使用藍色。底部內部未知 [TODO-01](../../renovation/AF-AFY10400/tracking.md#todo-01)。E-11。

自訂通知模式下：錯誤用自訂訊息；非空錯誤編號長度 >17 時加「錯誤編號：\n編號\n訊息說明：\n」，再接描述。成功且描述非空通常也顯示自訂訊息；成功僅收遮罩的子情境則在沒有訊息活動時隱藏遮罩。描述空、或關閉成功訊息時，也在沒有訊息活動時隱藏。原生通知模式下：沒有訊息活動時先隱藏遮罩；錯誤總是警示，長編號加「錯誤編號：\n編號\n」，再「訊息說明：\n描述」；成功描述非空、沒有底部接收者且成功通知開啟時警示「訊息說明：\n描述」。分支選用未知，不刪除任何已知反應。E-11/13；TODO-03。

**模式 B：先通知再回填的替代模式。** 先使用外部遮罩能力，若不可用或未成功则採頁面遮罩。收到傳輸成功但沒有訊息資料時，不執行本頁回應反應；錯誤先由外部訊息呈現能力或原生警示顯示（非空且長度>17編號的前綴没有「訊息說明：」），再執行成功／拒絕回填。成功時外部遮罩能力若存在則先收遮罩；完成时依原條件收頁面遮罩並重設共用選項。此與模式 A 的通知時機不同。E-11；[TODO-03](../../renovation/AF-AFY10400/tracking.md#todo-03)。

診斷警示原文：「Error :\nurl : 請求位址\nparams: 請求參數\nException: \n」，再逐項「屬性=值\n」。異常不能當匯出成功。E-11。

## CMP-COVER：遮罩取得、顯示與焦點嘗試

每次建立或取得頁面遮罩，先依已知條件調整尺寸；若當時焦點所在控制屬按鈕類，嘗試聚焦此頁所屬視窗；沒有符合的控制則不嘗試。取得焦點資訊或嘗試過程失敗時只留下診斷記錄，仍按傳入狀態顯示或隱藏遮罩。這是建立與重用共同的副作用，不代表瀏覽器一定讓視窗成為可見焦點。E-11（新增精確回查見 E-26）。觸發包含送出取得遮罩、自訂訊息顯示前，以及無活動的確認關閉後取得遮罩；完成處理若僅取既有遮罩而未經此取得行為，不追加聚焦嘗試。FLOW-06、AC-19；[TODO-07](../../renovation/AF-AFY10400/tracking.md#todo-07)。

## CMP-MESSAGE：自訂訊息生命週期

明確空值、缺省或空文字正規化成灰色「(無訊息內容)」；其他值轉文字，把字面反斜線加 n 與實際換行顯示為換行。按正規化後完整內容去重、保持首次加入順序，新內容以換行累積；重复仍重定位与聚焦。初次寬度按正規化訊息的呈現字串長度×15，含空值占位的呈現標記，限180–600px；後續只有內容寬小於588px且新長度公式較大時增長，不縮小。位置為頁面內容高度四分之一加捲動距離，水平居中加捲動距離；顯示遮罩，確定按鈕聚焦。精確樣式映射在 DESIGN。E-12。

首次顯示建立全頁首鍵反應，每個實例在第一個任意鍵先解除自己。首鍵為 Enter/Esc/空白且訊息視窗仍附著於頁面時才按確定並阻斷該鍵；其餘首鍵不關閉，其後第二鍵不再用该實例。若視窗在拖曳中已離開頁面，首個關閉鍵只解除本實例，不按確定、不阻斷；拖曳放開後重附著也不恢復已解除的首鍵反應。E-12。

按確定停止事件向上傳遞；若視窗存在於頁面，移除視窗、減少活動，没有活動則取得並隱藏遮罩、清空累積內容，最後執行已設定的確認反應。按鈕關閉本身不解除此前首鍵實例，因此關閉重開可能保留多個實例；每個實例只解除自己。E-12。

標題按下後暫停新的按下反應，保存指標相對視窗偏移、建立同尺寸位置的拖曳框，接受全頁指標移動／放開。移動阻断指標事件、框按偏移移動、真視窗離開頁面；放開時解除移動及放開反應，視窗採框位置、移除框、重新接受標題按下。E-12。AC-20 覆蓋首鍵與此中間狀態交錯；[TODO-07](../../renovation/AF-AFY10400/tracking.md#todo-07)。

## CMP-POLICY：條件式全頁政策與可信情境

功能資訊提供列印／下載政策及浮水印開關；是否啟用不能按頁名推論。[TODO-04](../../renovation/AF-AFY10400/tracking.md#todo-04)，E-06/07/08。啟用後首次載入建立全頁內容區的右鍵、列印、列印前、複製、剪下，以及所屬視窗按鍵的先行攔截。右鍵阻斷但沒有固定警示；Ctrl+A/X/S/P 阻斷並分別警示不開放全選／剪下／頁面儲存／列印；剪下、列印、列印前也阻斷及提示。列印隱藏所有頁面子區塊，顯示「依據資安政策，不開放列印功能」。E-07。

複製不阻斷。多行輸入有焦點時取其選取區間，否則文件選取；連續空白正規化为一个空格。與上次不同且非空，先建立獨立60秒到期以清除去重記錄，再立即記住正規化全文；長度>5000時將送出內容截至4997加...，按 `% # & 空格 + ? =` 順序轉成對應交接編碼；交接內容、功能、原正規化長度、時間。同內容不送出；舊到期不取消。t0複製A、t30複製B、t60的A到期會清除B記錄，因此t61再複製B会重新交接。外部記錄结果未知 [TODO-04](../../renovation/AF-AFY10400/tracking.md#todo-04)。E-07。
