## HANDOFF-01：可信資訊保護及複製稽核

觸發：本頁渲染前，由功能識別（先由交易識別，空時由頁面路徑）讀取功能資訊。若存在首筆資料，取得資訊保護及浮水印旗標；保護旗標成立才提供相關限制程序。不能從「有 script」推論本頁一定啟用。（E-07，LOGIC-01）

受信任資料：功能識別、保護與浮水印旗標；登入情境中的員工代號，代號為 null 才取姓名，缺登入者時空字串；伺服端日期時間 `yyyy-MM-dd HH:mm:ss`。字型站台情境另由主機 header 與設定取得。缺的工具實作不能由前端自行指定旗標／員工身分。（E-07，LOGIC-02）

| 方向 | 語意 | 格式／規則 | 消費或順序 |
| --- | --- | --- | --- |
| 可信輸入 | DATA-09 功能設定與登入者／時間 | 旗標／文字／日期時間；不是使用者輸入 | FLOW-09 決定保護与浮水印；先設定再註冊事件 |
| 稽核輸入 | 選取複製文字、功能識別、原選取長度、用於請求的當下時間 | 文字合併連續空白；非空且與上一段不同才交接；>5000 字截前4997＋`...`；保留未截取的長度 | 先設定上次複製內容與60秒清除，再編碼並交接記錄；無可見成功提示 |
| 呈現輸出 | 水印文字，DATA-09 | 身分＋換行＋服務端時間；適用旗標成立 | 使用者可見浮水印，需要未供應元件；不以本地算法假造 |

資料查詢失敗會捕捉並列印例外，不能推斷拒絕整頁。複製記錄成功／失敗、授权、持久化、保留期限不在來源，保持未知。目標 OPENAPI 未列上述責任或合法情境來源；缺這些不能把旗標硬編成 false。前端保留事件攔截與原文提示；服務负责可信設定与稽核落地。（E-07、TODO-03／04）

驗收需求：AC-12／13，保護是否啟用與字串／時間來源須由正式承接證據可定位；複製不因本地替身顯示就算完成稽核。水印離開事件原掛載名稱／handler 有疑點，不能擅自修正，見 TODO-07。

## HANDOFF-02：拒絕分支逐列結果

觸發：使用者通過前端非空與不重複檢核後送出，服務拒絕結果被交付給本頁回應流程。舊頁拒絕分支仍按每列被保人 ID 讀取逐列結果并填入第四欄；此分支不觸發下載。（E-05，FLOW-05，BR-05）

輸入：DATA-01／02 與依列配對的 DATA-04／05。輸出需要 DATA-06 以 ID 為鍵的逐列結果，必要文案由服務決定，前端不重製查詢／驗證。方法規格 E-11 描述先設定驗證結果、查詢匹配結果、拒絕時仍可能已有結果；不能由此補進選定 wire schema。

目標 API-01 成功已提供 rtnMap／fileName，但共通錯誤固定 `data=null`（E-10）；因此目前未承接拒絕結果需求。要保存逐列結果或確認改變拒絕可見行為，需後端／需求方可定位的承接或變更證據。此文件不替後端增加 payload 或新端點。錯誤時保留原結果、清空或顯示统一錯誤均未確認，不能自行選擇。（TODO-01，AC-09）

同時需確認服務回傳 `<br>` 訊息與基準要求文字節點的顯示差距：保留各方證據，不把未消毒內容注入 prototype，不把改良方案當既有需求。

## HANDOFF-03：入口訊息與回滾情境

觸發：首次渲染，從既有回應讀取訊息集合；型別錯誤改為無訊息，沒有訊息建空訊息。保留說明、錯誤編號、系統、類型、連結、回傳分類、異常欄；換行在共用程式中转換後供提示。（E-06）

呈現責任：前端先找外層訊息區，若回滾旗標成立則清除並停止；否则尝试第一筆通知，再依錯誤／異常條件提示。找外層或通知發生例外会被攔截，不因此停止後續提示。按鈕點擊另清外層訊息。（FLOW-01／08、DATA-08、CMP-01、AC-11）

需承接的服務／環境責任是合法入口訊息與回滾情境來源，及外層提供方式；前端负责可見提示／呈現順序。所選契約的 `code/msg/data` 无此七欄集合或回滾來源；不能以 `msg=success`造一組入口訊息。實際訊息文案、外層通知布局與元件未供應，TODO-04。

## 已有承接的責任與剩餘差距

API-01 定義匯出能力與資料對應，API-02 定義下载檔案；没有把整個舊業務方法搬回前端。方法規格中的安全查詢日誌、現況／歷史查詢、54欄 Excel、日期／時間轉換屬服務語意背景，不是根頁新增 UI，也沒有選定基準可證正式实现，仍由後端驗證。下載 binary 與加密參數差距為消費適配 TODO-02，不藉此要求後端恢復舊協定。
