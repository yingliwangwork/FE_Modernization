# 來源解析參考：JSP 與相依資源

本文件是目前的來源技術 profile；它不指定翻新後的技術棧。HTML prototype 是審閱載體，不是實作選型。

## 範圍與讀取

每輪只有一個 root JSP。先檢查其編碼宣告、實際位元組編碼與行尾；以可讀副本分析必要的轉碼，不修改 legacy 原件。記錄原始版本、行號基準與轉碼方式。JSP 的靜態文字未必等於最終畫面，條件、include 與 tag 輸出皆須追查。

依本頁行為追查 include、taglib、自訂 tag、共用 script、樣式、資源字串與直接呼叫的 handler。將每項依賴登錄到 tracking；不可取得的依賴建立具體 TODO。另一 JSP 的頁面內部不因連結而納入本輪 scope。

## 觀察點與轉譯

| 來源觀察點 | 要取得的事實 | 規格表達 |
| --- | --- | --- |
| directive、靜態／動態 include、自訂 tag | 實際引入條件、可見區塊、依賴角色 | 畫面構成及條件；解析細節留在證據 |
| scriptlet、expression、EL、條件 tag | 入口資料、預設值、渲染分支、角色判斷 | 前置條件、狀態、規則與分支 |
| form、hidden、action、method、submit 攔截 | 傳遞資料、動作選擇、已知交接 | 邊界輸入輸出；來源 URL 與欄位符號留在 tracking |
| JavaScript 事件、onload、timer、callback | 觸發、順序、guard、欄位連動、回應處理 | FLOW、BR、TR；不可只列函式名稱 |
| 非同步呼叫、回傳代碼、錯誤處理 | 已實作成功／空值／失敗分支與資料副作用 | 各條件的結果與後置狀態 |
| link、redirect、frame、popup、download | 目的、傳遞資料、視窗／頁面交接方式 | BOUND 及使用者所見導覽結果 |
| CSS、表格版面、圖示、tab order、焦點處理 | 資訊層級、對齊、可見性、尺寸、焦點順序 | SCR、UI、狀態差異與操作體驗 |
| 訊息資源、alert、confirm、例外區塊 | 文案、觸發條件、取消／確認結果 | MSG 與對應分支 |
| 權限 tag、session 檢查、角色旗標 | 顯示／可操作條件與可見拒絕行為 | 角色規則；不推導未取得的服務端授權 |

對使用者可辨識的 URL、檔案格式與代碼，依 [證據規則](evidence.md) 判斷是否屬可觀察契約；不可一律刪除。

## 後端邊界

若只看到送出的參數，規格可以確認送出條件與資料，但不能確認儲存結果、交易一致性、服務端驗證或權限。目標契約先依 [權威分工](authority.md) 查找指定後端產物；適用實作與觀察可協助核對，差異需列衝突，不能自行替代選定基準。不可取得時逐項建立 TODO，停止該未知分支的行為生成。

看到多個送出動作時分別盤點。hidden 欄位可能承載使用者不可見但影響流程的狀態，不能因不可見就忽略；也不能把所有 hidden 欄位直接做成可見 UI。

JSP 內直接執行後端行為時，讀 [耦合拆解方法](coupled-source.md) 逐段建立 LOGIC。只有呈現責任保留為前端行為；業務、存取、副作用與受信任情境需映射後端承接，缺少時建立 HANDOFF／TODO。語法掃描需包含 scriptlet、EL、自訂 tag、include 的間接呼叫、session 和 response 寫入，不只搜尋 form 或 script。

遇到 eBAF 自訂工具時，依 [後端設計參考](backend-reference.md) 按需查閱工具契約。工具名稱及文件中的示例不能證明本 JSP 使用該業務規則；仍需記錄實際呼叫參數、情境與本頁結果。

## UI/UX 證據強度

只有原始碼時，可描述其明確定義的結構、樣式與事件；不得聲稱已驗證執行畫面的像素一致性、實際效能或瀏覽器差異。沒有樣式或圖片時不得自行指定品牌色、圖示意義、響應式斷點或動畫。沒有鍵盤、焦點與返回行為證據時明列未知，不套用常見 UX。

已觀察的舊缺陷保留證據；是否修正另列變更提案與確認結果。prototype 如採用了新行為，必須能追溯至已確認變更，不能隱藏於版面整理中。
