## 1. 系統目的與契約範圍

INT-001：使用者選擇一組收承方式與商品屬性，依被保人及保單清單取得公會補通報的匯出結果與檔案。一次只處理一種組合；同一被保人的多筆保單以 Enter 分隔置於同列。這是來源操作說明與相關服務文件所支持的用途，並未證實其他公會作業目的。（E-005、E-012）

範圍內：SCR-001 的全部本頁控制、FLOW-001～FLOW-008 的已知分支。邊界包含服務的匯出／下載、入口訊息及共用的底部訊息、設定控制與稽核。外部訊息欄位的內部畫面、真正檔案內容、其他入口內部流程及未知字型／圖片／浮水印引擎不屬本頁契約；本頁已知交接仍保留。（E-001～E-014）

## 6. 規則與訊息

BR-001：从第一列开始，先檢查该列 ID 或保單是否完全空字串，再比較该 ID 与所有後列 ID。找到第一個問題即停止。因此前列的重複 ID 可优先于後列的空保單；不得改成全表先查空值。空白、大小寫差異不正規化。（E-003）

BR-002：零列迴圈無檢查且仍交出匯出；沒有最少一列、固定十碼必填、有效證號或保單格式前端限制。（E-003）

BR-003：成功与拒绝都按列 ID 回填响应结果。只有成功分支触发下载，且结果先更新。列结果不推导总体成败；即使总体成功，個別結果可包含查無保單說明。（E-003、E-012）

BR-004：共用受信任功能設定启用限制时保留 FLOW-007；浮水印另由独立设置决定。不自行判定本次必启用。（E-009）
