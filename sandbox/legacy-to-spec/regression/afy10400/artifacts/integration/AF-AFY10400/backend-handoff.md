## 2. 移交需求詳細

### HANDOFF-001：拒絕回應的逐列結果

觸發：FLOW-004 送出 DATA-001、002、004、005 后，服务判定失败。旧成功與拒絕都在回调读取 DATA-006，逐列显示後，只有成功取得 DATA-007 并下载。方法语意文件描述先建验证 map、随后查詢／比對更新结果，查无资料与產檔异常時旧回應仍可能含已建 map。前端不应自产「ID長度預為10碼」、「已匯出」或查无资料判断。（E-003、012）

输入：單一组合與有序 ID／对应多行保单。输出：依 ID 的结果文字，含来源所证实的「已匯出」和「被保人：{ID} 查無保單號碼：{policy}。」多段；同时需要整体拒绝描述。被信任业务资料、稽核身分与存檔路径由服务拥有。本来源无法证明拒绝 map 所有条件下的完整性，不能要求凭空填满每一 key。（E-003、012；TODO-006）

已承接部分：API-002 成功 payload 明确提供 map及檔名。未承接：基準錯誤 data=null，无法等价回填旧 TR-008。保留两端差距，不要求修改成自造 envelope；后端需提供可定位的承接或授权行为变更记录。中止／回滚／稽核原子性沒有明确保证，不由前端补偿。（E-010B、011）

核对 AC-009、010：在有已产生逐列结果的旧拒绝条件下，确认目标如何保留该可见信息，或提供经确认的契约变更。移交文件完成不代表此项解决。

### HANDOFF-002：檔案下載的等價交接

触发顺序：API-002 成功→先回填 UI-011→使用回传 DATA-007 请求文件，原呼叫明确同视窗。旧共用下载工具同步请求下载资讯，成功取得加密的檔名及路径，再经下载表单交接；真实加密／下载由服务负责，前端不组装服务存檔路径。方法文件描述交易目录及加密下载责任。（E-003、008、012D）

目标 API-003 已确认 binary 及 stub attachment header。移交并不是新增接口需求，而是确认正式 download adapter、同视窗体验与写入前／部分写入异常效果是否承接。输入仅 API-002 檔名；输出以目标正式契约为准，不把 legacy 加密字段写回目标 schema。业务取消、回滚、冪等未知。（E-011；TODO-003、006）

核对 AC-008、018：确认回填在下载之前、无新增产品下载按钮／窗口、下载错误与 binary 可区分；部分响应由正式环境证据确认。

### HANDOFF-003：受信任入口及共用條件責任

| 步驟／条件 | 已知输入／判断 | 已知结果与副作用 | 前端映射／证据 |
| --- | --- | --- | --- |
| 入口基础情境 | 共用 tag 提供资源／dispatcher；实作未提供 | 必要基址不能由前端默认值假造；所有产品字段不因此成为权限输入 | DATA-009，E-009；TODO-004 |
| 功能身分查询 | 先取业务 bean 名去底线；缺则從请求 URL 的 JSP 段取得；非空才查询功能资料，取首笔配置 | PD_CTRL=Y 注入政策；IS_WATERMARK=Y 独立开启浮水印；无资料不建立相应政策；异常只记录 | FLOW-007／008，E-009；TODO-004 |
| 登录者浮水印 | session 用户编号→缺编号姓名→缺用户空；服务时间 yyyy-MM-dd HH:mm:ss | 组合文字及配置给共用引擎；实际引擎未知，不能以本地时间／固定姓名作为可信输出 | DATA-009，FLOW-008，E-009；TODO-005 |
| 条件复制稽核 | 政策启用后复制選文字归一空白、非空且不同最近值 | 60秒去重；>5000字元截前4997+省略号，记录未截断长度、功能 ID、时间；原事件允许继续，稽核请求副作用不在原型执行 | BOUND-004，FLOW-007，E-009 |
| 入口讯息 | 服务输出集合，无資料建立0码空消息 | 先宿主首条，再各訊息异常／码分支；有回退 flag清除并提前退出；底部宿主与WI自身未知 | CMP-001，FLOW-001，E-006；TODO-001、005 |
| 稀有字型来源 | 指定入口 host 条件去清单取字型URL，否则本地资源 | 只定义资源选择，不推导字型外观或可用性 | E-009；TODO-005 |

API-001 的日期、N／false 控制旗标未被本 JSP 消费，亦未证实承接上述共用責任。列为需求移交而不指定 endpoint、框架或表设计。前端保留已定义禁印／快捷键反应，业务信任与副作用由服务或已确认共用基础设施承担。（E-009、011、012P）

核对 AC-011、015、016：确认受信任来源、条件分支、复制允许及去重／裁切、消息入口回退。无法取得共用资源不应删除已知政策分支。
