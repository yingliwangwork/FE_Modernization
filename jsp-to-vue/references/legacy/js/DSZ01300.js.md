# DSZ01300.js 公開契約

> 原始資源：`/DS/js/DSZ01300.js`

## **`new DSZ01300(element, QRY_TYPE, STOP_CODE, STOP_LEVEL, PAGEUI_KEY)`** — 直接掛載用法

### 用途

- 在指定容器建立逐層取得部門／單位的選擇介面，並依查詢類型與停止條件限制階層。

### 輸入

- `element`: [Element|String|Number] - 承載控制項的 DOM 元素、Prototype 元素識別或 CSS 選擇條件。
  - 非 DOM 值會先交給 `$$(element)`；有結果時採第一個元素，否則再以 `$(element)` 解析。
- `QRY_TYPE`: [Number|NumericString = 1] - 查詢類型；數值轉換結果為 `0`、`NaN` 或其他 falsy 值時改用 `1`。代碼由後端 `DSZ0_1300/queryOptions` 解讀。
- `STOP_CODE`: [Number|NumericString = 99] - 代碼停止條件；數值轉換結果為 falsy 時改用 `99`。
- `STOP_LEVEL`: [Number|NumericString = 99] - 階層停止條件；數值轉換結果為 falsy 時改用 `99`。
- `PAGEUI_KEY`: [Any = undefined] - 此模式必須省略或傳入 falsy 值；若為 truthy，建構式改走 PageUI 整合用法並忽略 `element`。

### 輸出

- `return`: [Object|undefined] - 初始化成功時回傳直接操作介面；缺少依賴或容器無效時為 `undefined`。
  - `return.get(node, rtnMap)`: [Function(Any=undefined, Object={}): Object|undefined] - 取得目前選擇，詳見 `dsz01300.get`。
  - `return.resize(isIgnoreSizeChange)`: [Function(Boolean=false): undefined] - 重排可視區域，詳見 `dsz01300.resize`。

### 對外功能

- 建立左右導覽、水平裁切區與階層式 `<select>`，並同步呼叫部門資料服務取得第一層選項。
- 每次選擇非終止選項時，移除其後所有層級並同步取得下一層。

### 副作用

- 在 `element` 中新增完整控制結構、樣式與事件，並以 `UI_Manager.addUIConfig(null, { resize })` 登錄版面調整。
- 初始化及階層變更均使用 `asynchronous: false` 的同步 Ajax，資料取得期間會阻塞頁面執行。
- 依賴 Prototype、`Ajax.Request`、`CSRUtil.isSuccess`、`UI_Manager` 及全域 `dispatcher`；Prototype 或容器無效時顯示警示，其他缺少依賴可能直接拋出例外。

## **`new DSZ01300(element, QRY_TYPE, STOP_CODE, STOP_LEVEL, PAGEUI_KEY)`** — PageUI 整合用法

### 用途

- 建立不立即插入頁面的部門階層控制項，並回傳可供 PageUI 掛載及讀寫的欄位描述。

### 輸入

- `element`: [Any = undefined] - `PAGEUI_KEY` 為 truthy 時完全忽略，可省略或傳入 `null`。
- `QRY_TYPE`: [Number|NumericString = 1] - 查詢類型，正規化規則同直接掛載用法。
- `STOP_CODE`: [Number|NumericString = 99] - 代碼停止條件，正規化規則同直接掛載用法。
- `STOP_LEVEL`: [Number|NumericString = 99] - 階層停止條件，正規化規則同直接掛載用法。
- `PAGEUI_KEY`: [String|Any] - truthy 值啟用 PageUI 整合；原值同時作為回傳欄位的 `key`。

### 輸出

- `return`: [Object] - PageUI 自訂欄位描述。
  - `return.type`: [String = "dom"] - 指示內容為既有 DOM 節點。
  - `return.key`: [Any] - 原始 `PAGEUI_KEY`。
  - `return.elem`: [HTMLDivElement] - 尚未掛載的控制項根元素。
  - `return.getFunc(node, rtnMap)`: [Function(Any, Object): Object|undefined] - PageUI 讀值函式，與 `dsz01300.get` 相同。
  - `return.setFunc(node, value, valuesMap)`: [Function(Any, String=undefined, Object): undefined] - 依 `value` 或 `valuesMap.COMMON_UNIT_SETTING` 重建階層；`valuesMap.DIV_NO` 可指定最後部門。

### 對外功能

- 建立與直接掛載用法相同的控制結構及初始選項，但交由呼叫端使用 `return.elem` 決定掛載位置。
- 以 `{type, key, elem, getFunc, setFunc}` 接入 PageUI 的欄位值交換流程。

### 副作用

- 以 `{PAGEUI_KEY}_DSZ01300` 作為 `UI_Manager` 的版面設定鍵，並在回傳前同步取得第一層選項。
- `setFunc` 會直接修改傳入的階層字串陣列副本、同步呼叫後端服務並重建全部選項。
- 其餘依賴、同步 Ajax 與警示副作用同直接掛載用法。

## **`dsz01300.get(node, rtnMap)`**

### 用途

- 將目前最深層的有效部門選擇整理成查詢條件與可還原的完整階層。

### 輸入

- `node`: [Any = undefined] - 為相容 PageUI 讀值介面保留；原始實作不讀取此參數。
- `rtnMap`: [Object = {}] - 接收結果的既有物件；falsy 時建立新物件。

### 輸出

- `return`: [Object|undefined] - 成功時為原 `rtnMap` 或新物件，並包含下列欄位；找不到有效層級時為 `undefined`。
  - `return.SELECT_TYPE`: [String] - 目前選擇的資料類型；終止選項可能直接以選項值作為類型。
  - `return.CHECK_TYPE`: [String|Number] - 檢核類型；一般層級嘗試轉為整數，無有效值時為空字串。
  - `return.DIV_NO`: [String] - 選取部門代碼；第一層或特殊終止分支可能為空字串。
  - `return.DIV_NM`: [String] - 從最末端往前找到的第一個非空選項顯示文字。
  - `return.COMMON_UNIT_SETTING`: [String] - 由第一層到最後一層的非空選項值，以逗號串接且尾端固定保留逗號。

### 對外功能

- 從最末層往前尋找第一個非空選項，依該層是否為停止選項組合 `SELECT_TYPE`、`CHECK_TYPE` 與 `DIV_NO`。
- 再從最末層向前彙整所有非空選項，形成可由 PageUI `setFunc` 還原的階層字串。

### 副作用

- 直接新增或覆寫 `rtnMap` 的五個輸出欄位。
- 沒有任何有效選項，或停止選項前缺少可提供值的層級時顯示警示並回傳 `undefined`。

## **`dsz01300.resize(isIgnoreSizeChange)`**

### 用途

- 依容器寬度重新配置階層選擇器的可視區及左右導覽按鈕。

### 輸入

- `isIgnoreSizeChange`: [Boolean = false] - 原意為強制略過尺寸變更判斷；因原始判斷式錯誤，實際無論傳值為何都會執行重排。

### 輸出

- `return`: [undefined] - 此操作不回傳是否發生版面變更。

### 對外功能

- 內容寬於外框時顯示左側導覽並將捲動位置移到較後層級；內容未超寬時隱藏導覽並使用完整寬度。

### 副作用

- 改寫外框、裁切區、內容區與導覽按鈕的寬度、位置、捲動量及顯示狀態。
- 原始碼將數值 `outlineWidth` 再讀取 `.offsetWidth`，得到無效數值，使「差異小於 20 像素即略過」的分支永遠無法成立。
