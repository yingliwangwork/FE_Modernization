# date.js 公開契約

> 原始資源：`/CM/js/date.js`

## **`toY2K(ROCdate)`**

### 用途

- 將民國紀年日期轉換為西元紀年的標準文字格式。

### 輸入

- `ROCdate`: [String] - 民國日期，年為一至三位，月日各兩位，可連寫或以斜線、連字號分隔，並可用前置負號表示民國前；支援格式詳見[代碼對照表](#代碼對照表)。

### 輸出

- `return`: [String] - 可解析且實際存在時回傳 `YYYY-MM-DD` 西元日期；否則照原值回傳。

### 對外功能

- 將民國紀年日期轉換為西元紀年的標準文字格式。

### 副作用

- 無

---

## **`isROCdate(srcData, yearLimit, isROCBefore)`**

### 用途

- 驗證民國日期文字的格式、曆法正確性與選擇性年份下限。

### 輸入

- `srcData`: [String] - 待判定的民國日期；支援格式詳見[代碼對照表](#代碼對照表)。
- `yearLimit`: [Boolean = true] - 是否限制為西元 1931 年以後，但仍例外接受民國 `000101`；傳入 `false` 取消限制。
- `isROCBefore`: [Boolean = false] - 是否允許以負號表示民國前年份。

### 輸出

- `return`: [Boolean = false] - 格式、實際年月日與年份限制均有效時為 `true`。

### 對外功能

- 驗證民國日期文字的格式、曆法正確性與選擇性年份下限。

### 副作用

- 無

### 對外功能

- 以兩個日期的時點差計算有符號的日數間隔。

## **`addDate(strDate, intYY, intMM, intDD)`**

### 用途

- 依年、月、日的順序對日期執行曆法加減，並處理閏日與短月邊界。

### 輸入

- `strDate`: [String] - 預期為 `YYYY-MM-DD` 西元日期。原始條件式不會正確拒絕長度錯誤的非空字串；空字串回傳空字串，`null` 或未定義值則會在讀取 `length` 時拋出例外。
- `intYY`: [Number] - 要加減的年數；呼叫端必須明確提供數值，未定義值會進入運算並使結果失效。
- `intMM`: [Number] - 要加減的月數；呼叫端必須明確提供數值。
- `intDD`: [Number] - 要加減的日數；呼叫端必須明確提供數值。

### 輸出

- `return`: [String] - 調整後的 `YYYY-MM-DD` 日期；月份或年份調整後原日不存在時，收斂至當月最後一日。空字串回傳空字串，其他無法形成有效日期的輸入可能回傳含 `NaN` 的文字，`null` 或未定義值則可能先拋出例外而不回傳。

### 對外功能

- 依年、月、日的順序對日期執行曆法加減，並處理閏日與短月邊界。

### 副作用

- 無

## **`getDutyDay(strDate, dudt, intMonth)`**

### 用途

- 將合約繳款日套用至指定相對月，並依當月實際天數調整。

### 輸入

- `strDate`: [String] - `YYYY-MM-DD` 基準日期。
- `dudt`: [String|Number] - 目標繳款日。小於或等於 28 時直接串接原值，因此呼叫端若要求兩位日格式，必須自行傳入補零字串。
- `intMonth`: [Number] - 相對於基準月的月份位移量。

### 輸出

- `return`: [String] - 目標月的繳款日；超過該月上限時收斂至月底。`dudt` 為未補零數值且不超過 28 時，結果可能是 `YYYY-MM-D`。

### 對外功能

- 將合約繳款日套用至指定相對月，並依當月實際天數調整。

### 副作用

- 原始實作會寫入多個未局部宣告的中間名稱，可能污染共用狀態。

- 建立可重複使用的日期時間文字格式契約。

## **`df.format(inDate)`**

### 用途

- 將西元日期時間依指定紀年、語系與樣板轉為顯示文字，包含月份、星期與 12/24 小時格式。12 小時制只會將大於 12 的小時減去 12，因此午夜仍顯示為 `00`，且不提供上午或下午標記。

### 輸入

- `inDate`: [String] - 支援的西元日期或日期時間文字，完整格式詳見[代碼對照表](#代碼對照表)。

### 輸出

- `return`: [String] - 依建構時樣板與語系產生的日期時間；輸入非字串或空字串時回傳空字串，格式無法解析時照原值回傳。若樣板完全沒有可識別標記，原始實作回傳空字串。

### 對外功能

- 將西元日期時間依指定紀年、語系與樣板轉為顯示文字，包含月份、星期與 12/24 小時格式。12 小時制只會將大於 12 的小時減去 12，因此午夜仍顯示為 `00`，且不提供上午或下午標記。

### 副作用

- 無

## 代碼對照表

### 日期輸入格式

| 適用契約 | 接受格式 | 補充規則 |
| --- | --- | --- |
| `stringToDate_ROC`、`isROCdate`、`toY2K` | `yMMdd`、`yyMMdd`、`yyyMMdd`、`y/MM/dd`、`yy/MM/dd`、`yyy/MM/dd`、`y-MM-dd`、`yy-MM-dd`、`yyy-MM-dd` | 月、日固定兩位；只有 `isROCBefore === true` 時才識別前置 `-` 為民國前。 |
| `stringToDate_Y2K`、`isADdate`、`isDate` | `yyyyMMdd`、`yyyy/MM/dd`、`yyyy-MM-dd` | 年固定四位，月、日固定兩位。 |
| `isROC13Mdate` | `yyMMdd`、`yyyMMdd`、`yyyyMMdd`、`yy/MM/dd`、`yyy/MM/dd`、`yyyy/MM/dd` | 月可為 `01` 至 `13`；不接受連字號分隔。 |
| `isROC13Month` | `yyMM`、`yyyMM` | 月可為 `01` 至 `13`。 |
| `isROC13MonthFirstDay` | `yyMMdd`、`yyyMMdd` | 月可為 `01` 至 `13`，日必須為 `01`。 |
| `SimpleDateFormat` 內部 `stringToDate`、`df.format` | `yyyyMMdd`、`yyyy/MM/dd`、`yyyy-MM-dd`、`yyyy-MM-dd HH:mm:ss`、`yyyy-MM-dd HH:mm:ss` 加任一單一字元及一至六位數字 | 最後一種格式原始正規表示式的分隔點未跳脫，尾碼只供格式匹配，不轉成毫秒。 |

### `SimpleDateFormat` 語系代碼

| 代碼 | 年份規則 | 月份與星期規則 |
| --- | --- | --- |
| `SimpleDateFormat.TW`、`"tw"`，以及除 `"en"` 外的任何值 | `yyyy` 顯示四位西元年；`yyy`、`yy`、`y` 先減去 1911，再依標記長度截取。 | `MMMM` 顯示完整中文月份，`MMM` 移除末尾「月」；星期使用中文。 |
| `SimpleDateFormat.US`、`"en"` | 所有年份標記均使用西元年，再依標記長度截取。 | `MMMM` 顯示完整英文月份，`MMM` 顯示前三個英文字母；星期使用英文。 |

### `SimpleDateFormat` 樣板標記

| 標記 | 輸出規則 |
| --- | --- |
| `yyyy` | 四位西元年，不受語系影響。 |
| `yyy` | 年份最多保留末三位；中文規則先轉民國年。 |
| `yy`、`y` | 年份最多保留末兩位；`y` 不代表不補零的單一年份。 |
| `MMMM` | 語系的完整月份名稱。 |
| `MMM` | 語系的月份縮寫。 |
| `MM`、`M` | 數字月份；`MM` 對小於 10 的值補零，`M` 不補零。 |
| `dd`、`d` | 月中日；`dd` 對小於 10 的值補零，`d` 不補零。 |
| `EEEE` | 語系的完整星期名稱。 |
| `EEE`、`EE`、`E` | 英文規則取星期前三個字母；中文規則取星期名稱最後一字。 |
| `HH`、`H` | 24 小時制；`HH` 對小於 10 的值補零。 |
| `hh`、`h` | 12 小時制；只將大於 12 的值減去 12，`hh` 對小於 10 的值補零。 |
| `mm`、`m` | 分；`mm` 對小於 10 的值補零。 |
| `ss`、`s` | 秒；`ss` 對小於 10 的值補零。 |
