# JSP 與相依資源解析

**職責**：定義來源讀取、語法觀察點、事件與生命週期分析。主張轉譯依 [evidence](../../guides/evidence.md)，依賴索引依 [dependencies](../../guides/dependencies.md)。

## 來源讀取

- **唯一 root JSP**：記原始版本、編碼宣告、實際 bytes、行尾及行號基準；不修改 legacy 原件。
- **逐檔核對**：依賴的編碼、行數及行尾個別檢查，不沿用入口或鄰近檔案紀錄。
- **工具盤點**：用 [source_inventory.py](../../scripts/source_inventory.py) 或等效工具取得雜湊、原始 bytes 行數及候選編碼的嚴格解碼結果。
- **解碼判定**：成功仍需核對宣告與可讀語意；失敗列未確認，不用替換字元或未驗證編碼掩蓋。
- **轉碼副本**：只在必要時建立，保留原件、方法與行號對應；工具輸出留 evidence。

```sh
python3 <skill>/scripts/source_inventory.py <file> --candidate utf-8 --candidate cp950
```

## 依賴與共用行為

| 觀察項 | 必須追查 |
| --- | --- |
| **引入來源** | include、taglib、自訂 tag、共用 script、style、字串資源及直接 handler |
| **條件輸出** | JSP 靜態文字不一定等於最終畫面；追渲染條件、include 與 tag 的實際輸出 |
| **本頁用法** | 從實際呼叫點追到條件分支與回應者，不能只列元件名稱 |
| **跨入口** | 另一 JSP 內部不因連結自動納入本輪，交接邊界仍要描述 |
| **請求鏈** | 所有回呼與例外處理者，包括 onException、診斷訊息、觸發及阻斷 |
| **訊息種類** | 初始化、非同步成功／拒絕、底部區、原生警示及自訂視窗分別核對 |
| **訊息生命週期** | 空字串／null／未定義／換行正規化、重複、累積、尺寸、重定位、清除及焦點 |
| **樣式生效** | 本頁匹配 selector、權重、引入順序、繼承及 :root 等規則，依 [style spec](../ui/style-spec.md) |

- **分支保留**：部署或情境是否選用未知時開 TODO，但保留來源已知反應、原文、焦點及副作用。
- **連續呼叫**：訊息元件要核對多次呼叫與邊界值，不只單次非空訊息。
- **例外完整**：只列 success／failure／complete 不代表例外分支已覆蓋。

## 事件作用範圍與時間關係

| 面向 | 必記內容及檢查 |
| --- | --- |
| **事件對象** | window／body／元件、註冊與解除時機、傳播階段、預設動作及阻斷 |
| **全域政策** | 保留頁面作用範圍，不為展示縮到產品容器；審閱工具豁免另標測試性質 |
| **計時器** | 每次建立、取消／重設、作用狀態及到期副作用；獨立計時器可能交錯 |
| **指標互動** | 拖曳按下／移動／放開、座標偏移、拖曳框、可見性與監聽重建 |
| **監聽身分** | 逐次註冊實例及解除對象；自我解除回呼不可改成被後續覆寫的共用變數 |
| **元件生命週期** | 建立、取得既有實例、顯示、隱藏、銷毀的條件式副作用 |

- **時間序列**：來源未取消舊計時器時，不自行加 debounce 或重新起算；不能只核對最終文字。
- **重開情境**：核對關閉後重開、不同關閉方式與首個事件，不只第一次顯示或確認按鈕。
- **間接副作用**：追焦點、視窗、導覽與全域狀態；未實測時保留已知觸發／嘗試，另列驗證限制。

## 語法觀察點與轉譯

| 來源觀察點 | 取得事實 | 契約去向 |
| --- | --- | --- |
| **directive／include／tag** | 引入條件、區塊與依賴角色 | SCR／UI／CMP |
| **scriptlet／expression／EL／條件 tag** | 入口資料、初值、渲染分支、角色判斷 | DATA／ST／BR |
| **form／hidden／action／method／submit 攔截** | 資料、動作選擇與交接 | BOUND；精確交換另查 API |
| **事件／onload／timer／callback** | 觸發、順序、guard、欄位連動與回應處理 | FLOW／BR／TR |
| **非同步／結果碼／錯誤處理** | 成功、空值、失敗分支及資料副作用 | TR／ST／DATA |
| **link／redirect／frame／popup／download** | 目的、傳遞資料與視窗／頁面交接 | BOUND 及導覽結果 |
| **CSS／版面／圖示／tab order／焦點** | 層級、對齊、可見性、尺寸與焦點順序 | UI／STYLE／ST |
| **訊息／alert／confirm／例外區塊** | 原文、條件、取消及確認結果 | MSG／TR |
| **權限 tag／session／角色旗標** | 顯示／操作條件及拒絕行為 | BR；不推導服務端授權 |

**符號映射留 evidence**；使用者可辨識 URL、格式與代碼依證據規則判斷契約性質，不一律刪除。

## 後端邊界

- **每個送出動作分開**：送出條件與資料有來源，後端結果須另查 [權威契約](../api/authority.md)。
- **hidden 不能忽略**：可影響流程，但不直接做成可見 UI。
- **混合責任掃描**：包含 scriptlet、EL、自訂 tag、include 間接呼叫、session 及 response 寫入，不只搜尋 form／script；依 [責任拆解](./responsibility-rules.md) 分配。
- **eBAF 工具**：依 [自訂工具語意](../api/backend-profile.md#自訂工具語意) 查實際參數、情境與效果。
- **分析與驗證分開**：來源解析確認所定義結構及行為，展示及真實驗證依 [UI 規則](../ui/writing-rules.md)。
