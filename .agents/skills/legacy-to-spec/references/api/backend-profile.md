# eBAF 後端契約產物查找

本文件用於查找本輪所需的後端產物與自訂工具契約。各產物的權威、版本選定與衝突處理依 [權威分工](authority.md)。

## 查找範圍

使用本輪指定的 `backend_root` 和交付索引。先查指定契約，再沿其引用查共通定義及必要業務規格；記錄實際讀取路徑、版本／雜湊和搜尋結果。下列路徑是查找候選，存在與適用性都需核對，不因命名宣告已取得產物。

| 候選產物 | 可支撐的內容 | 需另外取得的依據 |
| --- | --- | --- |
| `docs/OPENAPI.md` 或交付的 OpenAPI YAML／JSON | 已記載的介面、序列化、共通回應與例外 | 缺列欄位、身分機制、適用環境及實際部署狀態 |
| `docs/design/*Controller_design.md` 及相關設計 | 設計中已記載的入口、輸入輸出與校驗 | 設計是否已實作、全域序列化及例外定義 |
| `docs/design/*Service_design.md`、`docs/specs/**/*.md`、`docs/sa_spec/*.md` | 業務條件、處理順序、資料與副作用 | 未記載的對外暴露方式與 wire 定義 |
| 契約測試、驗證紀錄及適用實作 | 指定版本／環境的結果與差異 | 是否屬本輪指定基準；衝突不能自行裁決 |
| Mock／stub 指引與回應 | 替身環境明確提供的展示能力 | 正式契約、真實交易、權限與資料能力 |

`docs/OPENAPI.md` 是 Markdown 描述；不能只因檔名就交給 OpenAPI YAML／JSON parser 當作機器可讀契約。實際轉寫依 [API 規則](writing-rules.md)。

## 自訂工具語意

來源出現 eBAF 自訂工具時，依後端專案的工具索引查找 `.github/ebaf/*_copilot.md` 或其他已交付工具契約，只讀本頁實際使用的工具和相關章節。記錄工具版本、實際參數、使用條件及已定義效果；未取得語意時保留 LOGIC／TODO。

`.github` 的工作流程、skill、範本與示例可協助定位工具定義，不能證明本頁目標 API 或業務能力已存在。工具示例中的條件不自動成為根入口的規則。

查找結果寫入本輪 tracking；缺少產物只影響相應主張。前端翻新不修改後端原件或啟動後端開發流程。
