# eBAF 後端產物查找

**職責**：定位後端契約及自訂工具資料，不決定權威或補造能力；權威依 [authority](./authority.md)。

## 查找範圍

- **起點**：本輪指定 backend_root 與交付索引；先查指定契約，再沿引用追共通定義及必要業務規格。
- **紀錄**：實際讀取路徑、版本／雜湊、用途、適用範圍及搜尋結果，留 history/evidence。
- **候選不等於取得**：下表路徑只供查找，須核對存在及適用性。

| 候選產物 | 可支撐內容 | 另需依據 |
| --- | --- | --- |
| **`docs/OPENAPI.md` 或 OpenAPI YAML／JSON** | 已記載介面、序列化、共通回應及例外 | 缺列欄位、身分、環境與部署狀態 |
| **`docs/design/*Controller_design.md`** | 設計入口、輸入輸出與檢核 | 是否實作、全域序列化及例外定義 |
| **Service 設計、`docs/specs/**/*.md`、`docs/sa_spec/*.md`** | 業務條件、順序、資料及副作用 | 對外暴露方式與 wire 定義 |
| **契約測試、驗證紀錄及實作** | 指定版本／環境的結果及差異 | 是否屬本輪基準；有衝突不自行裁決 |
| **Mock／stub 指引與回應** | 替身環境的展示能力 | 正式契約、真實交易、權限與資料能力 |

**檔案格式要核對**：`docs/OPENAPI.md` 是 Markdown；不因檔名交给 OpenAPI YAML／JSON parser。轉寫依 [API 規則](./writing-rules.md)。

## 自訂工具語意

1. **定位工具**：依後端索引查 `.github/ebaf/*_copilot.md` 或已交付工具契約。
2. **限定讀取**：只讀本頁實際使用工具及相關章節。
3. **核對語意**：記工具版本、實際參數、使用條件與已定義效果。
4. **記錄缺口**：未取得語意時保留 LOGIC／TODO，不套用示例推定規則。

- **指引只供定位**：工作流程、skill、範本及工具示例不是本頁目標 API 或業務能力證據。
- **分析範圍**：缺產物只影響相應主張；不修改後端原件、不啟動後端開發。
