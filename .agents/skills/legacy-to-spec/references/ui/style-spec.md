# 樣式契約與映射

**職責**：定義 STYLE 的內容、來源判定及原型樣式映射。STYLE 保留在 [UI spec](../../templates/spec/ui-spec.md)，不另建 DESIGN 或 tokens 文件。

## STYLE 必填內容

每項 STYLE 記**元件／狀態、條件、規範值或公式、單位、來源與缺口**。

| 面向 | 有證據時須記錄 |
| --- | --- |
| **版面** | 資訊層級、排列、對齊、間距、容器、寬高、捲動及相對位置 |
| **文字** | 字型、尺寸、字重、行高、色彩、透明度及文字處理 |
| **形狀與層級** | 邊框、形狀、圖像、陰影、遮罩、固定／浮動定位 |
| **狀態／變體** | 可見／隱藏、焦點、選取、停用、錯誤及其他已知差異 |
| **環境限制** | viewport、responsive、列印或可及性需求 |

## 樣式來源判定

- **來源分開**：stylesheet、include、inline、共用元件及瀏覽器預設各自定位。
- **生效條件**：核對載入順序、cascade、權重、selector 作用範圍、繼承及實際狀態。
- **值的語意**：保留單位、相對尺寸、動態公式與執行條件，不能只摘色碼或第一個同名規則。
- **未知標記**：列具體 TODO，不用黑色、零、常見 spacing 或設計系統預設充當契約。
- **原生呈現**：來源未指定樣式時說明瀏覽器預設及限制，不推定固定品牌值。
- **變更分類**：缺陷、改良提案與確認變更分開記錄，不自行現代化。

## 原型樣式映射

| 映射項 | 必記內容 |
| --- | --- |
| **契約** | STYLE ID、UI／CMP／ST、條件及規範值 |
| **實作** | 原型元件、selector／property、資產與實際值 |
| **檢查** | AC-ID、viewport／資料／狀態、可見結果及預期 computed style |

- **依選定棧**：預設 [prototype.css](../../templates/prototype/prototype.css)；Angular／React 等沿其實際樣式方式，不強迫獨立 CSS 或 tokens.json。
- **共用重用**：核對來源版本、範圍及影響，不以名稱猜適用性。
- **模板限制**：骨架樣式只供啟動實作，不是產品佈局或配色依據。
- **真實核對**：按規格條件查可見結果與 computed style；語法或 metadata 通過不代表視覺一致。

**檢查與保存**：依 [驗收](../../guides/acceptance.md#第二階段原型完成關卡) 及 [輸出分類](../../guides/workflow.md#輸出分類與相對連結) 記截圖、結果與限制；未選原型不建立實作樣式或空目錄。
