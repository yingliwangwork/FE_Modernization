## 8. 演算法規格

### 8.1 動態欄位建立

**目的**：依欄位種類建立劃撥帳號、日期或金額輸入控制項。
**輸入**：`colkey`、`value`、`type`、`col_nm`。
**輸出**：`input`，日期型另以 `span` 包住 input 與月曆圖。
**虛擬碼**：
```
id ← colkey
IF type = 'date' THEN
    建立必填民國日期 input；顯示 Date.toInputROC(value 或空字串)
    change 時把 toY2K(輸入值或空字串) 寫回該列 record
    附加月曆圖；click 時 getCalendarFor(input)
    回傳 span
ELSE IF type = 'number' THEN
    建立必填金額 input；0 也需顯示；以 #,### 格式化
    blur 時增量更新 Temp_AMT、更新合計、格式化 input、把去逗號值寫回 record
    回傳 input
ELSE
    建立 required、readonly 的文字 input，值為 value
    回傳 input
END IF
```
**邊界條件**：空日期顯示與轉換結果取決於外部日期函式；金額空字串／非數字會使 `parseInt` 產生 `NaN`（D-04）；多列使用相同 `id`／`name`（D-11）；超過 maxlength 由瀏覽器截擋，程式未另處理。

### 8.2 檢核彈窗路由

**目的**：依確認回應的 `LINK_TO` 開啟指定檢核畫面。
**輸入**：含 `LINK_TO`、`QUERY_ID`、`CURRENT_DATE` 的 `parms`。
**輸出**：一個 popup 請求，或無動作。
**虛擬碼**：
```
IF LINK_TO = 'AIL0_1300' THEN
    起訖日期皆設 CURRENT_DATE
    以 dataObj JSON 開 AIL0_1300/query
ELSE IF LINK_TO = 'AIL1_1000' THEN
    把 QUERY_ID／CURRENT_DATE 對映為 QUR_*，分頁參數設 0
    開 AIL1_1000/query
ELSE
    不開視窗
END IF
```
**邊界條件**：空或未知 `LINK_TO` 不開窗；缺少回應欄位時 JSON 內容／popup 參數可能缺值，外部元件如何處理為 `[UNKNOWN]`。

### 8.3 新增明細

**目的**：在 grid 尾端加入待輸入列。
**輸入**：`LOAN_ID`、現有 records、`count`、`${TRANS_DATE}`。
**輸出**：增加一筆明細。
**虛擬碼**：
```
IF LOAN_ID 為假值 THEN alert 並停止
dataList ← grid 全部 records
count ← count + 1
加入 {序號:count, 帳號:'00041496', 日期:伺服器預設日, 金額:0, 備註:'', preCheck:'Y'}
grid 重載；呼叫 autoFormatToNumber()
```
**邊界條件**：`count` 非數值時 `+1` 可能字串串接或得到 `NaN`；grid 為空可加入第一筆；未限制最大筆數；每列的 ID 重複見 D-11。

### 8.4 確認送出

**目的**：驗證並送出整批人工入帳資料。
**輸入**：原因、表頭欄位、grid records、合計。
**輸出**：§6.1 請求及後續提示／重載。
**虛擬碼**：
```
IF 原因 = 17 AND 使用者不確認追償款提示 THEN停止
IF 原因 = 15 AND 使用者不確認入案款提示 THEN停止
IF valid1.validate() 為假 THEN停止
送出 transList JSON、LOAN_ID、BALC_REASON、去逗號 TOTAL_AMT
成功判定後：
    IF ERR_MSG 有值 THEN
        alert ERR_MSG；以 LINK_TO 路由 popup
    ELSE
        IF TIPS_MSG 有值 THEN alert TIPS_MSG
        grid 重載為一筆新序號、固定帳號、回應日期、金額 0 的列
        count/newSerNO ← 回應序號
    END IF
```
**邊界條件**：零筆狀態在現有刪除演算法下會被補回一筆；空 `LOAN_ID`／原因可到達請求（D-12）；回應缺序號會污染計數；重載後 `Temp_AMT`／合計未重設（D-03）；傳輸或業務失敗路徑見 D-02。

### 8.5 刪除、重新編號與合計重算

**目的**：刪除勾選列，保留至少一筆並重建序號與合計。
**輸入**：勾選 records、全部 records、`newSerNO`。
**輸出**：重載後 records、`count`、`Temp_AMT`、合計顯示。
**虛擬碼**：
```
selected ← grid 勾選 records
IF selected 筆數 = 0 THEN alert 並停止
base ← newSerNO；all ← grid 全部 records；result ← []
IF selected 筆數 = all 筆數 THEN
    result 加入 {序號:base, 帳號:${TRANS_NO}, 日期:${TRANS_DATE}, 金額:0, 備註:'', preCheck:'Y'}
    Temp_AMT ← 0；count ← base
ELSE
    counter ← 1；Temp_AMT ← 0
    FOR EACH item IN all
        FOR EACH delItem IN selected
            帳號與序號都相同則標記刪除並停止內迴圈
        END FOR
        IF 未標記刪除 THEN
            item.序號 ← parseInt(base) + counter
            result 加入 item
            Temp_AMT ← Temp_AMT + parseInt(item.金額, 10)
            counter ← counter + 1
        END IF
    END FOR
    count ← parseInt(base) + counter - 1
END IF
grid 重載 result；顯示格式化合計；previousRecord ← null
```
**邊界條件**：全選不產生零筆而補回一筆；同帳號同序號的多筆會一起符合比對；金額空值／非數字使合計成 `NaN`；`newSerNO` 不可解析時序號成 `NaN`；顯示與 backing 帳號不一致見 D-05。

### 8.6 初始化

**目的**：建立頁面、驗證器、明細表並掛上事件。
**輸入**：伺服器預設值、外部元件。
**輸出**：可操作畫面。
**虛擬碼**：
```
建立頁面標頭；註冊兩條自訂驗證
建立每頁 20 筆、可全選、不可排序的 grid 與五個資料欄
載入一筆預設資料；格式化數字
count/newSerNO ← 伺服器序號；合計顯示 0；原因選 99
綁定新增／確認／刪除 click
fix()；displayMessage()
```
**邊界條件**：任一外部全域不存在會中止後續初始化；`${TRANS_SERNO}` 空或不可解析會在腳本解析／執行階段失敗；原因清單無 `99` 時選取結果為 `[UNKNOWN]`。
