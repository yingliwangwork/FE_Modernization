## 1. 用途

本畫面供使用者查閱一筆貸款年期變更記錄，並列顯示變更前後的貸款期數、分期期數、定期期數、期別與還款方式。畫面同時顯示輸入及覆核的人員、日期與單位，以供追溯該筆變更；使用者閱畢後可返回呼叫端。

## 8. 演算法規格

### 8.1 共用非同步呼叫包裝

**目的**：依動作名組成服務位址，並把成功判定後的回應分派給呼叫端。

**輸入**：`actionName`、`params`、可選的 `successFunction`、可選的 `errorFunction`。

**輸出**：無直接回傳；以回呼交付 `response.responseJSON`。

**虛擬碼**：

```
發出 Ajax.Request(dispatcher + "/DSC8_0106/" + actionName, parameters=params)
收到 onSuccess(response) 時：
    resp ← response.responseJSON
    IF CSRUtil.isSuccess(resp) THEN
        IF successFunction 存在 THEN successFunction(resp)
    ELSE
        IF errorFunction 存在 THEN errorFunction(resp)
    END IF
```

**邊界條件**：`actionName`、`params`、`responseJSON` 為空或型別不符時的外部函式行為 `[UNKNOWN]`；本檔沒有傳輸失敗與例外回呼。此包裝沒有回傳 `Ajax.Request` 物件，呼叫端不能由本函式回傳值取消或等待請求。

### 8.2 查詢結果映射到畫面

**目的**：取得一筆變更記錄，依 DOM ID 把回應欄位放入 23 個顯示區。

**輸入**：四個伺服器渲染參數；成功回應 `resp.rtnMap`。

**輸出**：更新 `rtnMap` 與 `#table1` 內全部 `<div>`。

**虛擬碼**：

```
呼叫 ajaxPost("query", {LOAN_ID, APPLY_DATE, CHG_KIND, SEQ_NO}, success)
success(resp):
    rtnMap ← resp.rtnMap
    FOR EACH ele IN 所有符合 "#table1 div" 的元素：
        id ← ele.id
        ele.update(rtnMap[id] OR "")
    END FOR
```

**邊界條件**：

- 零個匹配元素時不更新畫面；目前原始碼機械計數為 23 個。
- `rtnMap` 為 null/undefined 時，第一次讀取 `rtnMap[id]` 即拋出錯誤，後續欄位不更新。
- 缺少某個鍵、鍵值為空字串、`null`、`undefined`、數字 `0` 或布林 `false` 時，都由 `|| ''` 顯示為空白；其中 `0`／`false` 的資訊會遺失，見 §15 D-03。
- `ele.update` 對字串採文字或 HTML 更新的語意由外部 Prototype 函式庫決定 `[UNKNOWN]`；若採 HTML 解析且服務值未淨化，會影響資料呈現與安全性，見 §14 U-03。
- 寫入目標是 `<div>`，沒有 `maxlength`、選項集合或數值型別限制。

### 8.3 關閉／返回分流

**目的**：依所在視窗環境返回呼叫端或上一頁。

**輸入**：全域 `window.isPopupWin`、`window.popupWinBack`、`window.parent.popupWin` 與本地 `rtnMap`。

**輸出**：呼叫其中一個外部返回介面。

**虛擬碼**：

```
IF window.isPopupWin 為真值 AND window.popupWinBack 為真值 THEN
    window.popupWinBack(rtnMap)
ELSE IF window.parent 為真值 AND window.parent.popupWin 為真值 THEN
    window.parent.popupWin.back(rtnMap)
ELSE
    CSRUtil.linkBack()
END IF
```

**邊界條件**：使用者可在非同步查詢完成前點擊按鈕，此時前兩條路徑收到 `undefined`，見 §15 D-04。程式只檢查回呼屬性是否為真值，沒有檢查其是否為函式；若是真值但不可呼叫，會拋出型別錯誤。跨來源父視窗存取是否拋錯及外部介面是否關閉視窗均 `[UNKNOWN]`。

### 8.4 初始化順序

**目的**：建立頁面外框、接線事件、啟動查詢及共用訊息呈現。

**輸入**：`window` 的 `load` 事件。

**輸出**：已初始化的畫面。

**虛擬碼**：

```
PageUI.createPageWithAllBodySubElement("DSC80106", "變更作業", "貸款年期變更記錄")
在 btn_close 註冊 click → doClose
doQuery()                     // 非同步，不等待完成
fix()
displayMessage()              // 顯示本次伺服器交易既有訊息
PageUI.resize()
```

**邊界條件**：任一步驟拋出例外時本檔沒有捕捉，後續初始化不執行。`displayMessage()` 在查詢完成前呼叫，查詢的回應不會由這條初始化呼叫呈現。
