## 7. 演算法

### A-01 驗證器建立

- 目的：註冊兩個自訂驗證並建立 form 驗證器。
- 輸入：欄位 class、R-EL-SYS-DT。
- 輸出/副作用：全域規則與 SD-VALID1。
- 虛擬碼：`TRANS_AMT_NOT0` 僅在 `v > 0` 回 true；`TRANS_DATE_CHK` 把 SYS_DT 轉 ROC，若 `diffDay(sysDT,v,true)>0` 回 false，否則 true；再以 focusOnError=true、immediate=false、mode=validator 建立 Validation。
- 邊界：比較/日期轉換的空值與無效字串行為 U-07、U-09。
- 來源位置：41–71。

### A-02 動態欄位建構

- 目的：依 type 建立日期、金額或唯讀帳號欄位。
- 輸入：colkey、value、type、col_nm。
- 輸出/副作用：F-TRANS-DATE / F-TRANS-AMT / F-TRANS-NO 及各 handler。
- 虛擬碼：type=date 時建 span、日期 input、E-CALENDAR，顯示 `Date.toInputROC(value或空)`；type=number 時建金額 input，值存在或等於 0 就格式化；其他 type 建 required readonly input。各列都沿用 colkey 作 DOM id。
- 邊界：多列時 id/name 重複為 RISK-01；value 為 0 的金額仍顯示；日期空值轉換 U-09。
- 來源位置：94–146。

### A-03 Ajax 成功分派

- 目的：統一呼叫 action 並按 `CSRUtil.isSuccess` 分派 callback。
- 輸入：actionName、params、successFunction、errorFunction。
- 輸出/副作用：S-CONFIRM。
- 虛擬碼：建立 Ajax.Request；HTTP onSuccess 讀 responseJSON；若 CSR success 且 successFunction 存在就呼叫；否則 errorFunction 存在才呼叫。
- 邊界：沒有 onFailure；responseJSON/CSRUtil 行為 U-04、U-05。
- 來源位置：73–91。

### A-04 Popup 路由

- 目的：依 LINK_TO 開啟兩種檢核畫面。
- 輸入：LINK_TO、QUERY_ID、CURRENT_DATE。
- 輸出/副作用：S-POPUP-AIL0 或 S-POPUP-AIL1。
- 虛擬碼：若 AIL0_1300，補開始/結束日期並以 dataObj JSON 傳送；否則若 AIL1_1000，組成六個參數；其他值不做事。
- 邊界：LINK_TO null/其他值無提示；popup 行為 U-10。
- 來源位置：147–174。

### A-05 新增列

- 目的：在 grid 尾端新增預設列。
- 輸入：F-LOAN-ID、SD-COUNT、現有全列、R-EL-INSERT-DATE。
- 輸出/副作用：T-INSERT 或 MSG-LOAN-REQUIRED。
- 虛擬碼：若 LOAN_ID 假值，alert 並停止；否則 count+1，push `{TRANS_SERNO:count, TRANS_NO:'00041496', TRANS_DATE:serverDate, TRANS_AMT:0, REMARK:'', preCheck:'Y'}`，重載 grid，呼叫 autoFormatToNumber。
- 邊界：只檢查 JavaScript truthiness，不 trim；全空白字串可通過。
- 來源位置：176–194。

### A-06 確認

- 目的：經確認/驗證後送出所有列。
- 輸入：F-BALC-REASON、SD-VALID1、全列、F-LOAN-ID、F-TOTAL-AMT。
- 輸出/副作用：S-CONFIRM 與 T-CONFIRM-ERR/T-CONFIRM-SUCCESS。
- 虛擬碼：原因 17/15 分別 confirm，取消即停止；valid1 false 停止；序列化全列與欄位送 confirm；回應分支見 §5。
- 邊界：15/17 之外沒有確認對話框；請求期間按鈕不停用。
- 來源位置：195–232。

### A-07 刪除與重編

- 目的：刪除選取列、重編序號並重算總額。
- 輸入：選取列、全列、SD-NEW-SERNO。
- 輸出/副作用：T-DELETE-NONE/T-DELETE-ALL/T-DELETE-PARTIAL。
- 虛擬碼：零選取則 alert；全選則重建一列並歸零；否則外迴圈走原列，內迴圈以 `TRANS_NO` 與 `TRANS_SERNO` 同時相等判定刪除，保留列序號改為 `parseInt(newSerNO)+counter`，金額以 `parseInt(...,10)` 加總；重載 grid、格式化總額、previousRecord=null。
- 邊界：重複 key 會一併刪除；非整數金額令總額成 NaN；全刪不產生空 grid。
- 來源位置：233–275。

### A-08 Checkbox 下拉資料補寫

- 目的：TableUI 選取 callback 中，替列內尚未寫回資料物件的 select 補值。
- 輸入：checkbox node 所在 tr、tr 的 `dataObj` attribute、列內所有 select。
- 輸出/副作用：缺少 `dataObj[select.name]` 時寫入目前 select.value。
- 虛擬碼：找 tr；取 `getAttribute('dataObj')`；遍歷 tr 內 select；對假值鍵寫入值。
- 邊界：attribute 是否為可寫物件與 TableUI 是否在列內產生 select 為 U-06；本頁已知欄位沒有 row select 控制項。
- 來源位置：283–299。

### A-09 初始化

- 目的：組裝完整畫面並註冊事件。
- 輸入：後端初值與外部函式庫。
- 輸出/副作用：T-INIT。
- 虛擬碼：PageUI 建頁；建驗證；建 pageSize 20、allSortable false、overDiv false 的 6 欄 grid；載入一筆；格式化；設定 count/newSerNO/總額/原因；註冊三按鈕；fix；displayMessage。
- 邊界：任何必要全域不存在時的例外處理未定義；依賴清單見 §12。
- 來源位置：277–340。
