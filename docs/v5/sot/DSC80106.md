## 7. 演算法

### A-01 Ajax 包裝與成功判定

- 目的：以共同位址前綴發出動作請求，將回應依共用成功判定分派。
- 輸入：`actionName`、`params`、可選 `successFunction`、可選 `errorFunction`。
- 輸出/副作用：建立請求；成功判定為真時呼叫成功回呼，否則只在錯誤回呼存在時呼叫它。
- 虛擬碼：

```text
request ← Ajax.Request(dispatcher + "/DSC8_0106/" + actionName, parameters=params)
ON request success:
    resp ← response.responseJSON
    IF CSRUtil.isSuccess(resp) THEN
        IF successFunction 存在 THEN successFunction(resp)
    ELSE
        IF errorFunction 存在 THEN errorFunction(resp)
    END IF
END
```

- 邊界：未傳成功回呼時成功結果被忽略；未傳錯誤回呼時非成功結果被忽略；transport/JSON 邊界見 U-03。
- 來源位置：57–74。

### A-02 查詢與逐欄回填

- 目的：以四鍵查詢並把 `rtnMap` 搬到所有表格 `div`。
- 輸入：R-04～R-07；成功回應 `resp.rtnMap`。
- 輸出/副作用：SV-RTN-MAP 更新，23 個容器更新。
- 虛擬碼：

```text
呼叫 A-01(actionName="query", params={LOAN_ID, APPLY_DATE, CHG_KIND, SEQ_NO}, successFunction)
successFunction(resp):
    rtnMap ← resp.rtnMap
    FOR EACH ele IN selector("#table1 div")（DOM 順序）:
        id ← ele.id
        ele.update(rtnMap[id] OR "")
    END FOR
```

- 邊界：23 個容器固定迭代；鍵缺少、值為 null/undefined/空字串/數字 0/布林 false 時均傳入空字串。`rtnMap` 本身為 null/undefined 時，第一次索引存取會拋錯且來源無 try/catch。繼承鍵與更新語意見 U-05/U-15。
- 來源位置：78–90。

### A-03 關閉路由

- 目的：依視窗環境選擇回呼或返回。
- 虛擬碼：

```text
IF window.isPopupWin 為真值 AND window.popupWinBack 為真值 THEN
    window.popupWinBack(rtnMap)
ELSE IF window.parent 為真值 AND window.parent.popupWin 為真值 THEN
    window.parent.popupWin.back(rtnMap)
ELSE
    CSRUtil.linkBack()
END IF
```

- 邊界：只選第一個成立分支；不驗證候選成員是否為函式；呼叫例外未捕捉；可傳 `undefined`。
- 來源位置：95–104。

### A-04 初始化順序

- 目的：在 load 後建立頁面、註冊行為並啟動查詢。
- 虛擬碼：

```text
PageUI.createPageWithAllBodySubElement("DSC80106", "變更作業", "貸款年期變更記錄")
綁定 btn_close.click → A-03
執行 A-02

```

- 邊界：S-01 非同步完成時序由外部函式庫決定；初始化不等待查詢便顯示既有訊息並 resize。
- 來源位置：110–124。
