## 7. 演算法

### A-FIX 固定標題定位

- 目的：在 scroll/resize 時調整 `bar1` 垂直位置。
- 輸入：`document.body.scrollTop`、`bar1.offsetHeight`；fallback 使用 `pageYOffset/window.innerHeight/document.bar1.document.height`。
- 輸出/副作用：`bar1.style.top` 或 `document.bar1.top`。
- 虛擬碼：

```text
fix():
  if getElementById('bar1') != null:
    a = body.scrollTop - bar1.offsetHeight + 30
    bar1.style.top = a
  else: stat()
stat():
  if document.bar1 != null:
    a = pageYOffset + innerHeight - document.bar1.document.height - 15
    document.bar1.top = a
  schedule stat() again after 2ms
```

- 邊界：正常文件已有 `bar1`，fallback 是否可達與舊 DOM API 行為見 U-LEGACY-DOM。
- 來源位置：35–54。

### A-SORT 明細排序

```text
if sort indicator text is ▼: set ▲ and sort_type='0'
else: set ▼ and sort_type='1'
set global sortCol=-1
call sortTable(col, rtnTable, 'rtnID', 0, sort_type, false, '#F0F8FF', '#FAFBE1')
```

- 五入口完整映射：E-SORT-INSR-TYPE=`col 2`、E-SORT-COMPANY=`3`、E-SORT-POLICY-NO=`4`、E-SORT-PROD-KIND=`9`、E-SORT-ISSUE-DATE=`14`；皆以 `rtnID` 為 row selector、`dataType=0`。
- 來源位置：64–76、1723–1768。

### A-ASYNC-CHECK 即時取回決策

```text
if validator fails: return
inputId = value of inputId
send S-ASYNC-CHECK(inputId)
on success:
  if resp.isIdError == 'Y':
    if user confirms exact warning: submit S-ASYNC
  else: submit S-ASYNC
```

- 邊界：不存在 error callback；`resp` 結構由 Prototype response callback 的第二參數提供，契約未知。
- 來源位置：120–141。

### A-SELECT 選列搬移

```text
i = selected radio value
copy TBL_NAME and 20 identity/date/policy values from row hidden[i]
copy PAY_AMT1..PAY_AMT19 from PAY_AMTn_[i]

display UPDATE_TIME_text from INPUT_TIME[i], but submit UPDATE_TIME from UPDATE_TIME[i]
enable edit/delete/cancel; show editor; parseEUDC()
```

- 來源位置：144–225。

### A-CLEAR 取消選取

```text

disable edit/delete/cancel; hide editor
```

- 來源位置：228–313。
