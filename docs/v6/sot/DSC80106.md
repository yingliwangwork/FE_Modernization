## 7. 演算法

### A-01 Ajax 成功分派

- 目的：把 transport success 分為應用成功或應用失敗。
- 輸入（含來源）：`actionName`、`params`、`successFunction`、可省略的 `errorFunction`。
- 輸出/副作用：建立 `Ajax.Request`；transport success 時最多呼叫一個 callback。
- 虛擬碼：

```text
建立對 <dispatcher>/DSC8_0106/{actionName} 的 Ajax.Request(params)
ON transport success(response):
    resp <- response.responseJSON
    IF CSRUtil.isSuccess(resp) THEN
        IF successFunction 為真值 THEN 呼叫 successFunction(resp)
    ELSE
        IF errorFunction 為真值 THEN 呼叫 errorFunction(resp)
    END IF
END
```

- 邊界：未提供 `errorFunction` 時應用失敗分支無動作；沒有 transport failure callback；method、編碼與 responseJSON 解析行為見 `U-AJAX-TRANSPORT`。
- 來源位置：57–74。

### A-02 查詢與依 DOM id 搬移資料

- 目的：用入口值查詢並把回應 map 搬到來源表格內所有 `<div>`。
- 輸入（含來源）：§4.2 的完整請求 schema；成功回應 `resp.rtnMap`。
- 輸出/副作用：寫 `STATE-RTNMAP`；更新 `V-RECORD-TABLE` 的所有 `F-*`。
- 虛擬碼：

```text
呼叫 A-01(actionName = "query", params = §4.2 schema, successFunction = callback)
callback(resp):
    rtnMap <- resp.rtnMap
    FOR EACH div IN 以選擇器「#table1 div」取得的 DOM 順序
        id <- div.id
        div.update(rtnMap[id] OR "")
    END FOR
```

- 邊界：map 值為空字串、數字零、布林 false、null 或 undefined 時都走 `|| ''` 而顯示空白；`rtnMap` 不可索引時會在第一個欄位取值時拋例外；`update` 是否解析標記見 `U-DOM-UPDATE`。
- 來源位置：78–90。

### A-03 關閉出口選擇

- 目的：依宿主能力選擇關閉/返回介面。
- 輸入（含來源）：`window.isPopupWin`、`window.popupWinBack`、`window.parent`、`window.parent.popupWin`、`STATE-RTNMAP`。
- 輸出/副作用：呼叫 §5 中一個出口。
- 虛擬碼：

```text
IF window.isPopupWin AND window.popupWinBack THEN
    window.popupWinBack(rtnMap)
ELSE IF window.parent AND window.parent.popupWin THEN
    window.parent.popupWin.back(rtnMap)
ELSE
    CSRUtil.linkBack()
END IF
```

- 邊界：僅檢查 `window.parent.popupWin` 真值，未檢查其 `back` 是否為函式；關閉早於查詢成功時傳入 `undefined`；跨來源 parent 存取的執行結果見 `U-CLOSE-HOST`。
- 來源位置：93–105。

### A-04 初始化順序

- 目的：建立頁面標題、事件、初始查詢、訊息與尺寸。
- 輸入（含來源）：load 事件與外部全域 API。
- 輸出/副作用：依固定順序呼叫外部 API 與 `A-02`。
- 虛擬碼：

```text
PageUI.createPageWithAllBodySubElement("DSC80106", "變更作業", "貸款年期變更記錄")
在 E-CLOSE 上註冊 click -> A-03
執行 A-02
執行 fix()
執行 displayMessage()
執行 PageUI.resize()
```

- 邊界：任何同步呼叫拋例外時，後續步驟不執行；`S-QUERY` 非同步回應可晚於其餘初始化步驟；外部 API 視覺語意見 `U-PAGEUI-RENDER` 與 `U-SHARED-RUNTIME`。
- 來源位置：110–126。
