## 7. 演算法

### A-01 行情結果格式化

- 對 §4.2 的完整欄序逐欄套用規則。地址 renderer 依綠 `$$`、藍 `@@`、紅 `**` 的順序逐次前置字串，因此三者同時成立時，最終由左至右顯示紅 `**`、藍 `@@`、綠 `$$`。
- 金額欄交給外部 `CSRUtil.$fmt(value, '#,###.####')`；日期交給 `Date.toROC`。外部函式的例外/空值語意見 `U-EXTERNAL-FUNCTIONS`。
- 來源：60–233。

### A-02 一般查詢

```text
reset valid1, valid2; APPLY_ID ← uppercase
IF valid1 fails: stop
scan tableA controls into chkMap, ignoring buttons, empty values, EQU_SIGN, select value 0,
and ignoring the two mode radio IDs when determining "other field"
IF CITY or TOWN exists AND no other field: alert and stop
build reqMap per §4.3; choose action by fromPublicBean; call S-02
```

來源：251–303。空城市且沒有任何條件仍會先由 VR-06 阻擋。

### A-03 土建融查詢

先轉大寫並執行 A-12 的土建融相容性檢查，再執行一般驗證與「僅縣市」檢查；通過後以 §4.3 schema 呼叫 S-03。來源：306–364。

### A-04 整批分戶查詢

先轉大寫並執行 A-12 的整批分戶相容性檢查，再執行一般驗證；不執行「僅縣市」額外檢查，通過後呼叫 S-04。來源：367–393。

### A-05 社區資料查詢

執行 A-12 的社區相容性檢查與 valid2；之後掃描非空 input 與非 0 select，若 `Object.keys(chkMap).length==2` 則顯示「僅縣市」提示；通過後呼叫 S-05。兩個 mode radio 均會進 chkMap，造成此數量判定與註解不一致，見 `D-COMMUNITY-CITY-CHECK`。來源：396–441。

### A-06 清除與模式切換

切換前先 reset form、重建鄉鎮預設項、清空承作結果；行情模式啟用/顯示行情元素，承作模式反向處理；最後勾選目標 radio、更新頁標題與按鈕 rowspan。清除按鈕單獨觸發時不清空行情 grid。來源：443–448、507–570。

### A-07 結果編號導航

```text
IF QUERY_TYPE=4: open DSA3_3310 with COMMUNITY_NO
ELSE map 1→DSA3_0500, 2→DSA3_0600, 3→DSA3_0700; unknown→return
windowName ← APPLY_ID with first "@" removed
open mapped prompt with APPLY_ID
```

來源：450–473。

### A-08 鄉鎮快取

每次城市變更先把鄉鎮重設為單一預設項；城市空值即停止；若 `TOWN_Map[city]` 存在且 length>0，重建快取選項，否則呼叫 S-06，保存回應陣列並重建。空陣列不視為命中，下次會重查。來源：475–505。

### A-09 承作分區查詢與結果

reset valid3 與承作結果；驗證失敗停止；依 §4.3 組 reqMap 呼叫 S-07。成功且 map truthy 時，以 `innerHTML` 逐一寫入 §4.2 的承作回應鍵，否則清空；truthy map 缺鍵或含 null 時沒有 fallback，實際呈現見 `U-RESULT-MISSING-KEY`。來源：571–608、650–658。

### A-10 Ajax wrapper

每次呼叫依 `fromPublicBean` 選 beanName，建立 Ajax Request；只在 HTTP onSuccess 內以 `CSRUtil.isSuccess` 分流 success/error callback。沒有 onFailure、onException、timeout。來源：611–627。

### A-11 行情 reqMap 建立

遍歷 `#tableA input` 與 `select`，排除 type=button，以 DOM id 作鍵、當前 value 作值；六個日期再經 `toY2K` 覆寫，最後附加 `showApplyId`。權威 schema 見 §4.3。來源：629–648。

### A-12 三種查詢相容性限制

| 查詢 | 只要非預設即禁止的欄位組 |
|---|---|
| 土建融 | `CASE_NAME`,`FLOOR`,`USE_FOR`,`USE_AREA1`,`RST_KIND`,`BUILD_AGE1/2`,`BUILD_MEASURE1/2` |
| 整批分戶 | `FLOOR`,`USE_FOR`,`USE_AREA1`,`RST_KIND`,`BUILD_AGE1/2`,`LAND_MEASURE1/2`,`BUILD_MEASURE1/2` |
| 社區資料 | `APPLY_ID`,`FLOOR`,`TRADE_DATE_BEG/END`,`APPR_DATE_BEG/END`,`USE_FOR`,`USE_AREA1`,`RST_KIND`,`BUILD_AGE1/2`,`LAND_MEASURE1/2`,`BUILD_MEASURE1/2` |

演算法依欄位的 `fieldName` 或 `useKindName` 串接「、」，移除末尾頓號後放入提示。來源：661–779。

### A-13 依 showApplyId 縮減結果欄

當不顯示受理編號時，先取完整欄序的 index 1 到倒數第 3 欄，去掉編號、買賣價、租金；迴圈再去掉買賣日，並用帶 `rowSpan:2` 的屋齡欄取代原屋齡欄。權威縮減欄序見 §4.2 與 `V-REDUCED-GRID`。來源：786–816。

### A-14 自訂驗證演算法

區間驗證以 `parseInt` 比較；任一值 NaN 即通過。地址/縣市、案名/縣市、地址/座標互斥與完整門牌規則詳見 §8。來源：818–879。

### A-15 Array.includes 相容補丁

若 `Array.prototype.includes` 不存在，以 `Object.defineProperty` 定義 SameValueZero 搜尋，支援負 fromIndex；descriptor 未明列 writable/configurable/enumerable。來源：915–965。
