ELSE 呼叫 errorFunction（若存在）

無 transport failure handler。來源 73–91。

### A-DELETE 刪除與重編

```text

IF selected 為空: alert MSG-DELETE-NONE；return

ELSE:
  FOR each record:

```
來源 233–275。
