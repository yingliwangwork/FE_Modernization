## 7. 演算法

### A-01 固定標題列

```text
on resize/scroll: if #bar1 exists, top = body.scrollTop - bar1.offsetHeight + 30
else start stat(): if document.bar1 exists, top = pageYOffset + innerHeight - document.bar1.document.height - 15; schedule stat() again after 2ms
```

`stat()` 的 document.bar1 舊式物件模型、2ms 永續 timer 與 `bar1.style` 隱含全域均依瀏覽器而異。來源 35–55。

### A-02 熱鍵與初始化

```text
register F2→btn_query, F8→btn_async, F9→editBtn, F10→deleteBtn

```

若條件式 E-ASYNC 不存在，F8 仍以 `document.frm.btn_async` 建立 ButtonAction；外部 HotKey 對 undefined 的行為未知。來源 56–62,86–91。

### A-03 排序

```text
read arrow node by idName
if innerText == "▼": set "▲", sort_type="0"; else set "▼", sort_type="1"
set implicit global sortCol=-1
call external sortTable(col, table, "rtnID", dataType=0, sort_type, false, "#F0F8FF", "#FAFBE1")
```

五入口參數完整列於 §4.5；資料列重複 id=`rtnID`。來源 63–77,1723–1768。


`valid` 為未宣告全域；具體焦點/提示由 DEP-07。來源 78–85。
