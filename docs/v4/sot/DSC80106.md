## 7. 演算法

### A-AJAX-POST 共用請求包裝

- 目的：向畫面專屬 dispatcher action 發出請求並依成功判定分派 callback。
- 輸入：`actionName`、`params`、可選 `successFunction`、可選 `errorFunction`。
- 輸出/副作用：建立一個 `Ajax.Request`；視判定呼叫一個 callback。
- 虛擬碼：

```text
建立請求，位址 ← dispatcher + "/DSC8_0106/" + actionName
請求參數 ← params
ON HTTP success(response):
    resp ← response.responseJSON
    IF CSRUtil.isSuccess(resp) THEN
        IF successFunction 存在 THEN successFunction(resp)
    ELSE
        IF errorFunction 存在 THEN errorFunction(resp)
    END IF
END
```

- 邊界：未設定 method、onFailure、onException、逾時或取消；`responseJSON` 為空/非物件時 `CSRUtil.isSuccess` 的行為屬 `U-04`。
- 來源位置：57–74。

### A-QUERY 初始查詢

- 目的：以四個伺服器提供的鍵載入單筆變更記錄。
- 輸入：四個 `F-HIDDEN-REQ-*`。
- 輸出/副作用：呼叫 `S-QUERY`；成功時設定 `F-HIDDEN-RTN-MAP` 並執行 `A-HYDRATE`。
- 虛擬碼：

```text
params ← {LOAN_ID, APPLY_DATE, CHG_KIND, SEQ_NO}
A-AJAX-POST("query", params, successCallback, 未提供 errorCallback)
successCallback(resp):
    rtnMap ← resp.rtnMap
    A-HYDRATE(rtnMap)
```

- 邊界：四值皆可能由 EL 產生空字串；來源不在呼叫前檢查。`resp.rtnMap` 為 null/undefined 時，後續取值會拋錯；是否可能發生為 `U-05`。
- 來源位置：78–91。

### A-HYDRATE 依 DOM id 搬移回應資料

- 目的：把回應 map 搬到所有表格內的 `<div>`。
- 輸入：`F-HIDDEN-RTN-MAP`、選擇器 `#table1 div`。
- 輸出/副作用：更新 23 個顯示節點的內容。
- 虛擬碼：

```text
FOR EACH ele IN queryAll("#table1 div")，依 DOM 順序：
    id ← ele.id
    ele.update(rtnMap[id] OR "")
END FOR
```

- 邊界：缺鍵、空字串、null、undefined、數字 0、布林 false 都走 `|| ''` 而顯示空白；truthy 值交由 Prototype `update` 解讀，是否作為 HTML 注入為 `U-03`/`D-RESPONSE-HTML`。迴圈也會處理未來新增到表格中的任何 `div`。
- 來源位置：83–88。

### A-CLOSE 三路退出

- 目的：依所在視窗環境把最新查詢 map 傳回呼叫端，或走共用返回。
- 輸入：window/parent 上的 callback 能力、`F-HIDDEN-RTN-MAP`。
- 輸出/副作用：呼叫三個目標之一。
- 虛擬碼：

```text
IF window.isPopupWin AND window.popupWinBack THEN
    window.popupWinBack(rtnMap)
ELSE IF window.parent AND window.parent.popupWin THEN
    window.parent.popupWin.back(rtnMap)
ELSE
    CSRUtil.linkBack()
END IF
```

- 邊界：查詢未完成或失敗時 `rtnMap` 為 undefined；第二分支未檢查 `back` 是否 callable；任一呼叫拋錯皆未捕捉。
- 來源位置：93–105。

### A-INIT 載入初始化順序

- 目的：建立標頭、綁定事件、查詢、調整版面與呈現既有交易訊息。
- 輸入：DOM、`PageUI`、Prototype `$`、`fix`、共用 `displayMessage`。
- 輸出/副作用：完整初始化頁面。
- 虛擬碼：

```text
PageUI.createPageWithAllBodySubElement("DSC80106", "變更作業", "貸款年期變更記錄")
observe(click on btn_close, A-CLOSE)
A-QUERY()                 // 非同步發出後立即往下執行
fix()
displayMessage()          // 顯示伺服器初始交易訊息，不等待 query
PageUI.resize()
```

- 邊界：任何一步同步拋錯都可能阻止其後步驟；來源無 try/catch。`displayMessage` 的契約由 `DEP-02` 擁有。
- 來源位置：110–126。
