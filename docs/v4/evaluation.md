# 雙產物 IR 評估規格

## 硬門檻

任一項不符即不得稱為最佳版本：

1. 高嚴重度語意遺漏為 0。
2. 欄位、服務、條件渲染、事件、驗證、演算法的來源盤點覆蓋率皆為 100%。
3. HTML/Markdown ID 唯一且雙向引用完整率為 100%。
4. 未知被寫成肯定句為 0；來源缺陷未被默默修正。
5. HTML 可離線呈現、無業務 script、無 JSP/EL、無外部資源。
6. 反向重建時，沒有任何會改變資料正確性或可觀察行為的必要猜測。
7. 所有外部資源使用完整路徑；所有資料表的欄序與逐列格數可由 HTML/MD 唯一重建。

## 加權分數（通過硬門檻後才計算）

| 面向 | 權重 | 評量 |
|---|---:|---|
| 語意覆蓋 | 40 | 來源原子 recall、服務/演算法/邊界完整性 |
| 視覺契約 | 20 | 區塊、文字、欄位、順序、群組、尺寸關係、狀態快照 |
| 跨產物一致性 | 15 | ID 可解析、無矛盾、無重複所有權、狀態雙向覆蓋 |
| 反向重建 | 15 | 只讀 IR 後重建的行為清單與來源比對 |
| 不確定性誠實度 | 5 | UNKNOWN/ASSUMPTION 精確，不少標也不濫標 |
| 可讀性與維護性 | 5 | 可定位、可抽換共用契約、無不必要重複 |

## 遺漏嚴重度

- **High**：會改變資料正確性、權限/安全、服務請求、狀態轉換、驗證結果，或主要可見行為。
- **Medium**：會改變次要視覺狀態、導覽細節、錯誤處理或邊界行為。
- **Low**：不影響功能的來源軌跡、維護資訊或細微版面差異。

## 回轉測試

反向重建者只能讀 `<screen>.html`、`<screen>.md` 與已列入 §12 的共用元件契約，
不得讀原始 JSP。輸出一份可執行風格的 JSP 重建稿或等價行為清單；獨立比較者再與原始 JSP 對照，
以 High/Medium/Low 記錄需要猜測、遺漏與額外主張。這個差異才是 JSP ↔ IR 保真度的主要證據。
