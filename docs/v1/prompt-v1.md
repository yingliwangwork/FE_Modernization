# v1 生成提示詞（最少提示詞基線）

研究流程第 1 點要求：「先使用最少提示詞讓模型生成初步的中間產物 SoT。」
本輪**刻意不提供模板、不提供撰寫規則**，僅給出目標與技術中立的要求，
目的是觀察模型的自然產出會遺漏什麼，作為 v2 模板與規則的依據。

## 實際使用的提示詞

```
閱讀這個 JSP 檔案，以高階語言、技術中立的方式記錄它的結構與功能，
輸出 Markdown。不要綁定任何特定前端框架。
```

## 生成條件

- 生成者可讀取：目標 JSP 全文、`/html/CM/header.jsp`、`/html/CM/msgDisplayer.jsp`
- 生成者**未**取得：v2 模板、撰寫規則、驗收條件檢查表、任何前一輪產物
- 不提供外部 JS（`PageUI.js`、`TableUI.js`、`CSRUtil.js`、`validation.js` 等）內容

## 已知的方法論限制（本輪）

本輪的「生成」與「差異分析」由同一個上下文執行，屬於自我審查，
偵測遺漏的能力弱於獨立審查。第 2 輪起應將生成與分析分離於不同的沙盒上下文。
詳見 `docs/v1/analysis.md` 的「方法論待改進項」。
