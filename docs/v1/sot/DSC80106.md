# DSC80106 — 貸款年期變更記錄

> 來源：`sourceCode/DS/C8/DSC8_0100/DSC80106.jsp`（240 行，BIG5）
> 複雜度層級：低

## 1. 概述

這是一個**唯讀的明細檢視畫面**，用來顯示某一筆「貸款年期變更」申請的完整記錄，
並列出變更前後的期數與還款方式對照，以及輸入者、覆核者的軌跡資訊。

畫面沒有任何可編輯欄位，唯一的互動是「關閉視窗」。
它被設計成從其他畫面以彈出視窗或子框架的方式開啟。

## 2. 頁面識別

| 項目 | 值 |
|---|---|
| 畫面代號 | `DSC80106` |
| 功能群組 | 變更作業 |
| 畫面標題 | 貸款年期變更記錄 |
| 後端服務前綴 | `DSC8_0106` |

## 3. 進入條件（由呼叫端傳入）

畫面在伺服器渲染時會取得下列四個值，作為查詢的鍵：

- `LOAN_ID` — 貸款帳號
- `APPLY_DATE` — 變更日期
- `CHG_KIND` — 變更種類
- `SEQ_NO` — 序號

## 4. 畫面結構

單一區塊，以表格排列「標籤 / 值」配對，共七列：

| 列 | 欄位 |
|---|---|
| 1 | 貸款帳號、變更日期、序號 |
| 2 | 原貸款期數、原分期期數、原定期期數 |
| 3 | 原期別、原還款方式 |
| 4 | 新貸款期數、新分期期數、新定期期數 |
| 5 | 新期別、新還款方式 |
| 6 | 輸入人員（代號＋姓名）、輸入日期、輸入單位（代號＋名稱） |
| 7 | 覆核人員（代號＋姓名）、覆核日期、覆核單位（代號＋名稱） |

底部為「關閉視窗」按鈕。

## 5. 資料欄位

全部欄位皆為顯示用，資料來源為查詢服務回傳的結果集：

`LOAN_ID`、`APPLY_DATE`、`SEQ_NO`、
`LOAN_PERIOD1`、`SPR_PERIOD1`、`FIX_PERIOD1`、`TERM_TYPE1`、`RETURN_TYPE1`、
`LOAN_PERIOD2`、`SPR_PERIOD2`、`FIX_PERIOD2`、`TERM_TYPE2`、`RETURN_TYPE2`、
`INPUT_ID`、`INPUT_NM`、`INPUT_DATE`、`INPUT_DEPT`、`INPUT_DEPT_NM`、
`CONFIRM_ID`、`CONFIRM_NM`、`CONFIRM_DATE`、`CONFIRM_DEPT`、`CONFIRM_DEPT_NM`

字尾 `1` 代表變更前的舊值，字尾 `2` 代表變更後的新值。

## 6. 行為

### 6.1 進入畫面

1. 建立頁面外框（標題列、功能群組名稱）
2. 綁定「關閉視窗」按鈕
3. **自動執行一次查詢**，不需使用者操作
4. 顯示後端回傳的訊息（如有）
5. 調整版面尺寸

### 6.2 查詢

以進入條件的四個鍵呼叫後端 `query` 服務，成功後把回傳的資料填入畫面。
填值方式是**以欄位名稱對應畫面上的顯示區塊**：回傳結果中每個 key
對應畫面上同名的顯示區塊，找不到對應值時顯示空字串。

### 6.3 關閉視窗

依開啟方式決定關閉行為：

1. 若自身是彈出視窗且呼叫端註冊過回呼 → 執行回呼並把查詢結果回傳給呼叫端
2. 若位於框架中且父層有彈窗管理器 → 透過父層執行回呼並關閉
3. 其他情況 → 回到上一頁
