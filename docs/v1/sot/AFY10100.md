# AFY10100 — 公會通報查詢

> 來源：`sourceCode/AF/AFY10100.jsp`（2012 行，BIG5）
> 複雜度層級：高

## 1. 概述

本畫面供人員以身分證字號／統一編號查詢某一被保人或要保人在
**壽險公會通報系統**中的保單通報資料，並提供保障與保費的彙整統計、
明細列表，以及對單筆通報資料的修改與刪除功能。
另提供「即時向公會取回資料」的功能。

## 2. 頁面識別

| 項目 | 值 |
|---|---|
| 畫面代號 | `AFY10100` |
| 畫面標題 | 公會通報查詢 |
| 後端服務前綴 | `AFY1_0100` |

## 3. 畫面結構

畫面由上而下分為六個區塊：

1. **查詢條件區**
2. **保障項目彙整表**
3. **保費資料彙整表**
4. **資料編輯區**（預設隱藏）
5. **新制通報資料明細列表**
6. **代碼說明區**

### 3.1 查詢條件區

| 欄位 | 型態 | 說明 |
|---|---|---|
| 身份證字號/統一編號 | 文字輸入 | 必填 |
| 同步更新公會回檔狀態 | 核取方塊 | 僅在特定條件下顯示 |
| 契約角色 | 下拉選單 | 被保人 / 要保人 |
| 保單效力 | 下拉選單 | 有效 / 無效 / 全部 |
| 姓名 | 唯讀顯示 | 查詢結果帶出 |
| 生日 | 唯讀顯示 | 查詢結果帶出 |
| 公會資料取回日期 | 唯讀顯示 | 查詢結果帶出 |
| F2查詢 | 按鈕 | 送出查詢 |

### 3.2 保障項目彙整表

以三欄並排的方式呈現 19 個保障項目，每個項目顯示四個數值：
**合計、同業合計、收件、承保**，金額以千分位格式化。

保障項目依序為：
身故、完全失能或最高級失能、失能扶助金、特定事故、初次罹患、
醫療限額、醫療限額自負、醫療日額、住院手術、門診手術、門診、
重大疾/傷病、重大傷燙傷、癌症療養、出院療養、喪失工作能力、
喪葬費用、銜接原醫療限額之自負額、分期給付。

### 3.3 保費資料彙整表

三個項目（年繳保費、躉繳保費、超額(彈性)保險費），
每個顯示合計、收件、承保三個數值，另顯示操作者。

### 3.4 資料編輯區

預設隱藏，於使用者在明細列表選取一筆資料後才顯示。
包含該筆通報資料的所有欄位，其中部分為唯讀顯示，部分可編輯：

- **唯讀**：通報方式、公司別、被保人 ID、被保人生日、保單號碼、保單分類、
  險種分類、險種、保單狀況、保單狀況生效日期、主約保單號碼、契約生效日、
  契約生效時分、契約滿期日、契約滿期時分、要保書填寫日、保費、保費繳別、
  保費繳費年期、保單狀況生效時分、資料寫入時間、公會取回序號、
  來源別、銷售通路、商品代碼
- **可編輯**：19 個保障金額欄位、保經代分類、要保人姓名、要保人身分證號碼、
  要保人出生日期、要保人與被保險人關係、被保險人性別（下拉）、
  公、自費件（下拉）

底部按鈕：F9修改、F10刪除、取消。

### 3.5 新制通報資料明細列表

每列包含選取用的單選鈕，以及下列顯示欄位：

序號、通報方式（可點擊開啟明細）、公司別、保單號碼、銷售通路、商品代碼、
保單分類、險種分類、險種、保單狀況、身故保額、醫療限額、醫療日額、
契約生效日、契約滿期日、要保人姓名、通報時間。

其中「通報方式、公司別、保單號碼、險種、契約生效日」五欄可點擊表頭排序，
排序方向以三角形符號指示。

列表下方在特定權限條件下顯示「F8即時取回公會資料」按鈕。

### 3.6 代碼說明區

八條靜態說明文字，解釋銷售通路、保單分類、險種分類、險種、繳別、
保單狀況等代碼的意義，以及彙整欄位的計算範圍與 F8 的使用方式。

## 4. 熱鍵

| 按鍵 | 功能 |
|---|---|
| F2 | 查詢 |
| F8 | 即時取回公會資料 |
| F9 | 修改 |
| F10 | 刪除 |

## 5. 行為

### 5.1 進入畫面

1. 調整版面定位
2. 註冊熱鍵
3. 初始化驗證（身份證字號/統一編號不得為空值）
4. 顯示後端回傳的訊息

### 5.2 查詢 / 修改 / 刪除

三者皆為**整張表單以 POST 方式送出**至後端對應的處理位址，
差別僅在送出前設定的目標位址不同：
`doQuery`、`doEdit`、`doDelete`。

### 5.3 即時取回公會資料

1. 先執行欄位驗證，未通過則中止
2. 以輸入的身分證字號呼叫後端檢核服務
3. 若後端回報格式不符檢核規則 → 跳出確認對話框
   「輸入值 ⟨值⟩ 不符身份證/統一證號檢核規則，請確認，是否要繼續作業?」
   使用者確認後才送出；取消則中止
4. 格式正確則直接送出表單

### 5.4 選取明細資料

使用者點選某列的單選鈕時：

1. 將該列所攜帶的全部欄位值複製到編輯區的對應欄位
2. 啟用「修改」「刪除」「取消」三個按鈕
3. 顯示編輯區
4. 重新套用造字字型處理

### 5.5 取消

清空編輯區所有欄位、取消所有單選鈕的選取狀態、
停用三個按鈕、隱藏編輯區。

### 5.6 開啟通報明細

點擊列表中的「通報方式」連結時，以該列的全部欄位組成查詢字串，
在新視窗開啟通報資料明細畫面。

### 5.7 排序

點擊可排序欄位的表頭時，切換該欄的升冪／降冪並重新排列列表，
同時切換表頭的三角形指示符號。

## 6. 資料欄位

單筆通報資料包含下列欄位：

`TBL_NAME`、`INSR_TYPE`、`CMNY_CODE`、`COMPANY_NAME`、`I_ID`、`I_BIRTHDAY`、
`I_GENDER`、`POLICY_NO`、`POLICY_CAT`、`POLICY_DUTY`、`PROD_KIND`、`PROD_CODE`、
`STATUS`、`LST_CHG_DATE`、`LST_CHG_TIME`、`MAIN_POLICY_NO`、`ISSUE_DATE`、
`ISSUE_TIME`、`LPS_DATE`、`LPS_TIME`、`SIGN_DATE`、`PREM`、`PAY_FREQ`、
`PAY_PERIOD`、`PAY_TYPE`、`PAY_AMT1`～`PAY_AMT19`、`BROKTYPE`、`A_NAME`、
`A_ID`、`A_BIRTHDAY`、`RELATION`、`UPDATE_TIME`、`INPUT_TIME`、`SER_NO`、
`OIU_IND`、`SALE_CHNL`

彙整資料的欄位命名規則為
`⟨項目⟩_Tot`（合計）、`_TotSame`（同業合計）、`_Rr`（收件）、`_LN`（承保）。
