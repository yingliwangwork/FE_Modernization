# 迭代執行協定

本協定定義每輪迭代的自動化執行方式與人工介入節點。
v2 起適用。

## 1. 沙盒隔離

研究流程第 3 點要求「每輪迭代都必須使用沙盒環境，不可繼承上一次迭代的狀態」。

**污染源是模型上下文，不是檔案狀態。** 因此隔離方式為**冷啟動的子代理**：

| 角色 | 可讀取 | 禁止讀取 |
|---|---|---|
| 生成者（每個樣本一個） | 目標 JSP、`docs/vN/template.md`、`docs/vN/rules.md`、共用 include | `docs/v(N-1)/**`、其他樣本的 SoT、任何前輪產物 |
| 分析者（每輪一個） | 三個樣本原始碼、本輪三份 SoT、驗收條件、缺口分類法（GAP-1～GAP-8） | 前輪的具體遺漏清單（僅給分類法，不給答案） |
| 統籌（主線） | 全部 | — |

**不採用 git worktree**：worktree 隔離檔案狀態，但同一 session 內的上下文照樣繼承，
對本研究的污染源無效。

**分析者只拿分類法、不拿前輪的 33 項具體遺漏**：
給分類法是為了讓輪次之間的統計可比較；不給具體項目是為了讓它必須獨立找出來，
否則就變成對答案。

## 2. 一輪的執行步驟

```
1. 統籌：準備 docs/vN/{template.md, rules.md}（上一輪的產出）
2. 生成：平行啟動 3 個冷啟動子代理，各產出 docs/vN/sot/<樣本>.md
3. 分析：啟動 1 個冷啟動子代理，產出 docs/vN/analysis.md
4. 統籌：審閱分析結果，抽樣覆核（至少 3 項）確認分析者沒有誤判
5. 統籌：產出 docs/v(N+1)/{template.md, rules.md}
6. 統籌：撰寫 docs/vN/README.md 記錄本輪決策
7. 統籌：commit（前綴 iter(vN):）
8. 統籌：評估收斂判準 → 繼續或詢問使用者
```

## 3. 受控變因

每輪**只改變模板與規則**，其餘條件固定：

- 樣本固定（`docs/v1/samples.md`，不更換、不擴充）
- 子代理可讀取範圍固定
- 外部共用 JS 在 v2 仍為 out-of-scope，標為未知

> **v2 為何不同時納入共用 JS**：一次只動一個變因。
> 若 v2 同時改了模板規則又擴大了可讀範圍，遺漏數的變化就無法歸因。
> 共用層 SoT 另開軌道處理，見 §6。

## 4. 收斂判準

每輪結束後計算：

| 指標 | 定義 |
|---|---|
| `N_total` | 遺漏總項數 |
| `N_high` | 「照 SoT 重寫會行為不同」的項數 |
| `N_new` | 本輪新出現、前輪未見的遺漏類型數 |

**達成收斂**（同時滿足）：

- `N_high == 0`
- `N_total ≤ 5`，且全部為低嚴重度
- `N_new == 0`（連續兩輪）

**判定停滯**（觸發人工介入）：

- 連續兩輪 `N_total` 降幅 < 15%，或
- 連續兩輪 `N_high` 未下降

## 5. 人工介入節點（human on the loop）

下列情形**必須停下來詢問使用者**，其餘一律自動進行：

| # | 節點 | 為何需要人 |
|---|---|---|
| H1 | 達成收斂判準 | 確認 SoT 品質可接受，並決定是否進入轉換階段 |
| H2 | 判定停滯 | 迭代方法本身可能需要改變，不是再跑一輪能解決 |
| H3 | 缺陷的處置涉及業務語意 | 「保留現況」或「修正」是業務決策，不是技術決策 |
| H4 | 需要擴充或更換樣本 | 會破壞輪次可比較性，必須明示同意 |
| H5 | 發現原始碼中的資安問題 | 需要判斷是否另行通報，不應只記在 SoT 裡 |
| H6 | 單輪成本顯著超出預期 | 使用者有權決定是否繼續投入 |

## 6. 平行軌道（不阻擋主迭代）

| 軌道 | 內容 | 時機 |
|---|---|---|
| T1 共用層 SoT | `PageUI.js`、`TableUI.js`、`CSRUtil.js`、`validation.js` 等共用腳本各一份 SoT。`jsp-to-xxx` 分支已有 25+ 份雛形可併入 | 主迭代收斂後，或使用者指示時 |
| T2 反向驗證 | 由 SoT 反推 JSP 再與原檔比對，作為「互轉無損」的客觀判準 | v3 導入 |

## 7. 稽核軌跡

每輪產出固定為：

```
docs/vN/
  README.md      本輪決策記錄與結論
  sot/           三份 SoT
  analysis.md    差異分析
docs/v(N+1)/
  template.md    下一輪模板
  rules.md       下一輪規則
```

每輪一個 commit，前綴 `iter(vN):`，message 內含樣本、遺漏統計、產出、待處理項。
