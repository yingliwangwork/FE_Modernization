## 三項關鍵發現

### 1. 規則有寫但沒擋住，比規則沒寫更難修

7 項 OVER-2 全部違反 v2 的 A3（「不知道就標未知」），但 A3 白紙黑字寫在規則裡。
失效原因：作者**知道一半**——驗證了本檔範圍內的前提，
就把「本檔範圍內為真」當成「執行期為真」。
A3 沒有提供判斷「這個結論是否越出可讀範圍」的操作程序。

→ v3 把 A3 改成可執行的檢查：絕對語氣關鍵字掃描 + 逐前提的範圍檢查。

### 2. `[ASSUMPTION]` 密度與範圍外依賴成反比

| 樣本 | `[ASSUMPTION]` 每百行 | 範圍外相依 | 未知項 |
|---|---|---|---|
| DSC32200 | 2.61 | 中 | 35 |
| DSC80106 | 1.25 | 低 | 23 |
| AFY10100 | **0.20** | **最多（12 項）** | 27 |

最複雜、範圍外依賴最多的樣本標了最少推論。
形式上每條規則都遵守，實質上推論被藏進肯定句。

→ v3 新增 E6：把 §14 未知清單當**反查索引**用，
逐一檢查全文有無依賴該未知項的肯定句。

### 3. 存在性檢查有效，正確性沒有任何檢查

§K 的 17 項全是「有沒有寫」，實測**確實奏效**：
§3 渲染契約覆蓋率零遺漏、標籤文字零誤差、樣式使用次數全部精確。

但 5 項事實錯誤**全部**集中在「作者憑印象補上的行號與計數」，
因為 §K 沒有任何一條要求回頭驗證已寫下的內容。

> 附帶佐證：分析者自己開了 OVER-3 這個分類，然後在自己的報告裡
> 也犯了同一種錯（渲染點報 266、實際 259；引入檔缺陷數報 8/4/0、實際 6/3/1）。
> 統籌覆核時發現。這說明問題不在個別執行者的謹慎程度，而在缺乏機械驗證。

→ v3 新增 K.2 正確性驗證與 K.3 過度掃描，並要求在 §18 附上核對指令。
